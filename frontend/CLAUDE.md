# frontend/CLAUDE.md

## 레이어

`app → components → lib → data` 방향으로만 import한다. ESLint(`no-restricted-imports`)가 강제한다.

| 위치                     | 두는 것                                                                  | 두지 않는 것                       |
| ------------------------ | ------------------------------------------------------------------------ | ---------------------------------- |
| `src/app/`               | 라우트, 페이지 조합, `searchParams` 해석, 메타데이터                     | 판정·변환 로직                     |
| `src/components/<기능>/` | 기능 화면 조각. 상태가 필요할 때만 `"use client"`                        | 판정 로직, 데이터 파일 직접 import |
| `src/components/ui/`     | shadcn 컴포넌트. 기능을 모른다                                           | 도메인 import                      |
| `src/lib/`               | 판정, 인코딩, 데이터 조회 같은 순수 함수. React·Next를 import하지 않는다 | UI                                 |
| `src/data/`              | 크롤러가 쓴 JSON. `lib`의 조회 함수만 읽는다                             | 손으로 고친 값                     |

- 서버 컴포넌트가 기본이다. 클라이언트 컴포넌트는 인터랙션이 있는 잎(leaf)에만 두고, 데이터는 서버에서 props로 내려준다.
- 문구·판정 규칙처럼 화면 여러 곳이 쓰는 값은 `lib`에 한 번만 정의한다.

## 테스트

- `lib`의 export 함수는 `*.test.ts`를 같은 폴더에 두고 vitest로 테스트한다. 판정 규칙이나 공유 링크 형식을 바꾸면 테스트부터 고친다.
- 컴포넌트 렌더링 테스트는 두지 않는다. 화면은 `/gate`의 브라우저 QA로 확인한다.
