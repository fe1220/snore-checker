# 스펙: 병원 카드 정보

상태: 승인

사용자가 10월 3일 새벽 채팅에서 아래 범위를 승인했다. 근거는 [가상 사용자 테스트](../03-clinic-data/persona-test.md)와 채움률 분석이다.

## 문제

- 지역 보기에서 첫 카드가 안과·정신건강의학과일 때 "왜 여기가 나와?"에서 멈춘다(가상 사용자 P1, P6).
- 목록의 병원은 모두 수면검사를 하는 곳인데, 화면 어디에도 그 기준이 없다.
- 동네 의원인지 대학병원인지 알 수 없다. 대기 시간과 비용 감이 달라 고르는 데 필요하다.

## 정한 것

| 항목 | 내용 |
|---|---|
| 목록 위 문장 | "모두 수면검사(수면다원검사)를 하는 병원이에요." 기존 "방문 전에 전화로 확인해 주세요."와 한 문단 |
| 병원 규모 | 카드에 "의원", "병원", "종합병원", "상급종합병원"을 보여준다. 학회 목록 병원은 같은 줄에 "· 수면학회 등록" |
| 정렬 (지역 보기) | 학회 목록 병원 먼저, 같은 묶음 안에서는 지금처럼 주소 가나다순. 내 주변 순은 거리만 본다 |
| 넣지 않는 것 | 대표 진료과(안과 등이 오히려 눈에 띈다), 개원 연수·의사 수(품질 점수처럼 읽힌다), 진료시간·주차·교통(채움 3~9%) |

**왜 "수면클리닉이 가능한 병원"이 아니라 "수면검사를 하는 병원"인가:** 목록 기준이 레즈메드 수면다원검사 병원찾기와 심평원 "수면다원검사 실시기관" 신고다. "수면클리닉"은 정해진 기준이 없는 말이다.

## 데이터

| 필드 | 값 | 출처 |
|---|---|---|
| `kind` | `"의원" \| "병원" \| "종합병원" \| "상급종합병원" \| null` | 심평원 스냅샷의 종별. "상급종합"은 "상급종합병원"으로 바꾼다. 그 밖의 종별(치과병원, 정신병원 등)과 공공 데이터와 맞추지 못한 레즈메드 병원은 null |

- 채움: 744곳 중 737곳(분석 결과). null인 병원은 규모 줄을 그리지 않는다(학회 등록이면 "수면학회 등록"만).
- 크롤러 타입, 프론트 타입, JSON을 같은 작업에서 바꾼다.

## 화면

```
서울수면의원                         2.3km
[의원 · 수면학회 등록]
서울특별시 강남구 논현로 648
[전화하기]  [병원 정보 보기 ↗]
```

- 규모와 학회 등록은 기존 배지 자리 하나에 합친다. 줄을 늘리지 않는다.
- 접근성 측정(88개)을 그대로 통과해야 한다.

## 추가 (10월 3일)

- 지도(마커, 확대·축소, 내 위치 중심)는 넣지 않는다. "내 주변 순으로 보기"가 같은 질문에 답하고, 지도 조작은 대상 사용자에게 목록 스크롤보다 어렵다. 길 찾기는 카드 주소를 눌러 네이버 지도로 넘긴다.
- 주요 버튼 이름은 가는 곳(레즈메드 상세, 병원 홈페이지, 네이버 지도)과 상관없이 "병원 정보 보기" 하나로 둔다. 세 곳 모두 병원 정보를 보여주고, 카드마다 이름이 다르면 왜 다른지 헷갈린다. 어디로 갔는지는 분석의 `target`에 남는다.
