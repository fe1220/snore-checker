# 가상 사용자 플로우 테스트

> **목적:** 가상 페르소나 8명으로 첫 화면부터 병원 카드까지 가며 문구와 흐름에서 멈출 만한 곳을 찾은 기록이다. 실제 사용자 근거는 아니다.
>
> **결론:** 공통 문제 6개 중 3개(지도 링크 중복, 검사비 문구, 공유 리포트 첫 줄)는 고쳤다. 3개는 결정이 필요하다(지역 목록 순서, 신호 약함의 위험 막대, "잘 모르겠어요" 표시).

2026-10-03 새벽, 배포본(744곳 반영)으로 진행했다. 에이전트가 페르소나 8명을 만들어 Playwright로 첫 화면부터 병원 카드의 주요 버튼까지 1회씩 갔다. 분석 요청(GA, 메타 픽셀, Vercel)은 막았다.

> 실제 사용자 근거가 아니다. 문구와 흐름에서 멈출 만한 곳을 찾는 용도로만 쓴다. 실제 40~60대 사용자 테스트는 따로 한다.

## 공통 문제와 처리

| 문제 | 처리 |
|---|---|
| 지도로만 가는 카드에 같은 지도 링크가 둘 | 고침: 주요 버튼이 지도면 주소는 글자로만 둔다 |
| "내가 내는 돈"이 누가 내는지 모호 | 고침: "검사비는 건강보험 적용 후 약 12~14만 원이에요" |
| 지역 보기가 주소 가나다순이라 첫 카드가 정신과·안과 | **결정 필요**: 학회 등록 → 이비인후과·수면 전문 순으로 올리고 진료과를 보여줄지 |
| 공유 리포트 첫 줄이 답과 안 맞고, 누가 보냈는지 없음 | 고침(10월 3일): 첫 줄을 조건문 "요즘 낮에 졸리고 피곤했다면, 수면무호흡증 때문일 수 있어요"로 바꿔 답과 상관없이 맞게 했고 "당신"을 뺐다. 공유받은 화면의 머리말을 "함께 자는 사람이 옆에서 보고 답한 리포트예요"로 바꿨다 |
| 신호 약함에도 위험 막대가 나옴 | **결정 필요**: 약함 단계에서 위험 카드를 접을지 |
| "잘 모르겠어요" 답이 리포트에 안 나옴 | **결정 필요**: "모르는 질문 n개, 오늘 밤 옆에서 확인해 보세요"를 넣을지 |
