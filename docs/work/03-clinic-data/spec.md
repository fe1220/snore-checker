# 테크스펙: 병원 데이터 보강

상태: 승인

조사 세 건에서 나온 문제를 고친다. 근거는 [data-quality](../../research/data-quality/README.md), [supply-gap](../../research/supply-gap/README.md)에 있다.

| 문제 | 근거 | 고치는 방법 |
|---|---|---|
| 레즈메드 좌표가 틀리다 | 333곳 중 53곳이 500m 넘게, 12곳이 5km 넘게 어긋난다. "내 주변 순으로 보기"가 틀린 순서로 나온다 | 좌표를 공공 데이터 값으로 바꾼다 |
| 병원이 없는 지역이 많다 | 레즈메드 목록만으로는 시·군·구 230곳 중 124곳, 인구 20.4%가 0곳이다 | 수면다원검사 실시기관 전체(약 745곳)로 넓힌다. 0곳 지역 인구가 11.0%로 준다 |
| 시·도가 틀린 병원 2곳, 병원명이 77자인 병원 1곳 | 레즈메드 원본 오류 | 공공 데이터 값으로 바꾼다 |

병원 홈페이지를 직접 긁는 방식은 쓰지 않는다(표본 18곳 중 진료시간을 뽑을 수 있던 곳이 1곳). 네이버 예약·플레이스는 robots.txt가 전체를 금지해 수집하지 않는다.

## 데이터 출처

| 출처 | 가져오는 것 | 갱신 |
|---|---|---|
| 레즈메드 병원찾기 (기존) | 병원 337곳의 이름, 주소, 전화, 상세 페이지 주소 | 매주 자동 |
| 심평원 "전국 병의원 및 약국 현황" (공공누리 1유형, 출처 표시) | 수면다원검사 실시기관 735곳의 이름, 주소, 전화, 좌표, 홈페이지 | **분기마다 사람이 파일을 받아 스냅샷을 다시 만든다** |
| 대한수면연구학회 수면클리닉 찾기 | 학회 목록에 있는 병원 95곳 | 매주 자동 |

- 심평원 파일은 분기마다 나오고, 올려둔 사이트(opendata.hira.or.kr)의 robots.txt가 전체를 금지한다. 자동으로 받지 않는다.
- 진료시간은 넣지 않는다. 심평원 파일의 진료시간은 레즈메드 병원 333곳 중 15곳에만 있다. 공공 API 키가 나오면 채움률을 먼저 확인하고 따로 정한다.

## 스냅샷

- `crawler/scripts/build_hira_snapshot.py`: 받은 압축 파일에서 `1.병원정보서비스`와 `10.…특수진료정보서비스`를 읽어, 특수진료 코드가 `SH`(수면다원검사 실시기관)인 기관만 `crawler/data/hira-psg.json`으로 쓴다. Python 표준 라이브러리만 쓴다(`zipfile`, `xml`). 원본 파일(60MB)은 저장소에 넣지 않는다.
- 실행: `python3 crawler/scripts/build_hira_snapshot.py "<압축 파일 경로>"`. 절차는 `crawler/README.md`에 적는다.

```ts
// crawler/data/hira-psg.json
type HiraSnapshot = {
  version: string // "2026.6"
  items: {
    ykiho: string // 암호화 요양기호. 기관을 가리키는 키
    name: string
    kind: string // 의원, 종합병원, 상급종합 …
    address: string
    phone: string | null
    homepage: string | null
    lat: number
    lng: number
  }[]
}
```

## 데이터 계약 (바뀌는 것)

```ts
type Hospital = {
  id: string // 레즈메드 slug. 공공 데이터에만 있는 병원은 "hira-" + ykiho 해시 앞 10자
  name: string
  region: Region // 주소에서 다시 계산한다
  address: string
  phone: string | null
  lat: number
  lng: number
  sourceUrl: string | null // 레즈메드 상세 페이지. 공공 데이터에만 있는 병원은 null
  homepage: string | null // 공공 데이터나 학회 목록에 있는 병원 홈페이지
  listed: boolean // 대한수면연구학회 수면클리닉 목록에 있음
}

type HospitalData = {
  crawledAt: string
  hiraVersion: string // "2026.6"
  items: Hospital[]
}
```

## 합치는 규칙

레즈메드 병원과 스냅샷 병원을 아래 순서로 맞춘다. 학회 목록도 같은 규칙으로 맞춘다.

1. 전화번호(숫자만)가 같고, 정리한 이름이 비슷하거나 주소(도로명+건물번호)가 같다.
2. 전화번호가 달라도 주소(도로명+건물번호)가 같고 정리한 이름이 비슷하다.

- 전화번호만 같으면 맞추지 않는다. 같은 번호를 쓰는 다른 기관이 실제로 있었다.
- 이름만 같아도 맞추지 않는다. 동명 병원이 17개 이름 45곳이다.
- 후보가 둘 이상이면 맞추지 않는다.
- 이름 정리: 괄호와 법인명 접두어("(의)…재단", "의료법인 …"), 공백을 지운다.

| 경우 | 예상 건수 | 처리 |
|---|---|---|
| 양쪽에 다 있음 | 약 332 | 레즈메드의 id·이름·주소·전화·`sourceUrl`을 쓰고, **좌표와 홈페이지는 스냅샷 값**을 쓴다. 레즈메드 이름이 40자를 넘으면 스냅샷 이름을 쓴다 |
| 레즈메드에만 있음 | 약 5 | 레즈메드 값을 그대로 둔다(폐업·이전으로 추정되지만 확인할 수 없다) |
| 스냅샷에만 있음 | 약 408 | 스냅샷 값으로 새 병원을 만든다. `sourceUrl`은 null |

- `region`은 모든 병원에서 주소 첫 단어로 다시 계산한다. "강원특별자치도"·"전북특별자치도"는 강원·전북으로, "전남광주통합특별시"는 뒤의 구 이름이 동구·서구·남구·북구·광산구면 광주, 아니면 전남으로 본다. 목록에 없는 값이 나오면 수집을 실패시킨다(기존 규칙).
- 맞춘 건수, 못 맞춘 병원, 좌표가 1km 넘게 바뀐 병원을 크롤러 로그에 남긴다.
- 합친 결과가 600건 미만이면 저장하지 않는다(기존 200건 기준을 올린다). 학회 목록 수집이 실패하면 `listed`만 모두 false로 두고 저장한다.

## 크롤러

| 파일 | 역할 |
|---|---|
| `crawler/scripts/build_hira_snapshot.py` | 분기 파일 → `crawler/data/hira-psg.json` |
| `crawler/src/sources/hira.ts` + 테스트 | 스냅샷 읽기와 검증 |
| `crawler/src/sources/sleepnet.ts` + 테스트 + 픽스처 | 학회 목록 파싱 (`javascript:openView({...})` 안의 JSON) |
| `crawler/src/match.ts` + 테스트 | 이름·주소·전화 정리와 맞추기 (순수 함수) |
| `crawler/src/merge.ts` + 테스트 | 세 출처를 `Hospital[]`로 합치기, `region` 계산 (순수 함수) |
| `crawler/src/index.ts` | 수집 → 합치기 → 건수 검사 → 저장 |

## 프론트

- **출처 줄:** "레즈메드 병원찾기 · 건강보험심사평가원 2026년 6월 · 10월 3일 수집".
- **카드 버튼** (두 개를 유지한다)

| 병원 | 왼쪽 | 오른쪽 (주요) |
|---|---|---|
| 레즈메드에 있음 | 전화하기 | 병원 정보 보기 → 레즈메드 상세 |
| 공공 데이터에만 있고 홈페이지 있음 | 전화하기 | 병원 홈페이지 보기 → 홈페이지 |
| 공공 데이터에만 있고 홈페이지 없음 | 전화하기 | 지도에서 보기 → 네이버 지도 검색 |

- 네이버 지도 링크는 `https://map.naver.com/p/search/{병원명 + 시·군·구}`를 프론트에서 만든다. 수집이 아니다.
- 레즈메드에 있는 병원은 주소를 누르면 같은 지도 링크가 열린다.
- **학회 배지:** `listed`가 true면 병원명 옆 `Badge` "수면학회 등록". 인증 제도인지 확인하지 못해 "인증"이라고 쓰지 않는다.
- **분석:** `clinic_click`에 `target`(`resmed` / `homepage` / `map`)을 붙인다. 북극성 지표(병원 외부 링크 클릭)는 세 가지를 합친 값이다.
- 지역별 건수와 "전체 · N곳"은 데이터에서 계산하므로 고칠 것이 없다.

## 테스트

| 대상 | 방법 |
|---|---|
| `match.ts` | 전화+이름 일치, 전화만 같고 다른 기관(맞추지 않음), 주소+이름 일치, 후보 둘(맞추지 않음), 법인명 접두어 정리 |
| `merge.ts` | 세 경우의 필드 출처, 좌표 교체, 40자 넘는 이름 교체, `region` 계산(특별자치도, 통합특별시), 모르는 시·도 예외 |
| `sleepnet.ts`, `hira.ts` | 픽스처 파싱, 필수 필드 없는 건 |
| `hospitals.json` | 600건 이상, id 중복 없음, 모든 좌표가 한국 범위 안, `sourceUrl`이 있으면 레즈메드 주소 |
| 화면 | `/gate` 브라우저 QA: 세 가지 카드, 배지, 내 주변 순 정렬 |

## 리스크

| 리스크 | 대응 |
|---|---|
| 스냅샷이 낡는다(분기 파일을 사람이 받아야 한다) | 화면 출처 줄에 기준 시점을 적는다. 갱신 절차를 `crawler/README.md`에 둔다. 폐업한 병원이 남을 수 있어 "방문 전에 전화로 확인해 주세요"를 목록 위에 한 번 적는다 |
| 병원을 잘못 맞춰 좌표나 배지가 다른 병원에 붙는다 | 전화번호만, 이름만으로는 맞추지 않는다. 애매하면 맞추지 않는다 |
| 공공 데이터에만 있는 병원은 원 페이지 링크가 없다 | 홈페이지나 지도 검색으로 보낸다. 과제의 크롤링 원 페이지 링크는 레즈메드 337곳이 충족한다 |
| 공공 데이터 좌표가 건물 단위로 정확한지 따로 검증하지 못했다 | 시·군·구 단위로는 332/333이 맞았다. 정렬 기준으로만 쓴다 |
