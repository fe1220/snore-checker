## 결과 (2026-10-03)

- 검증은 별도 에이전트(verifier, design-reviewer)가 했다. `make gate` 통과: vitest 31개, 크롤러 테스트, e2e 161개.
- **V4 실패:** 남은 홈페이지 160곳 중 2곳이 실제 브라우저에서도 열리지 않는다(제주대학교병원 400 Bad Request, "준비중" 페이지 400). 크롤러가 400을 살아 있는 것으로 본다. 후속 작업으로 넘긴다.
- **CI 크롤링:** 푸시 후 수동 실행(GitHub Actions, 미국 러너)에서 52곳이 지워졌다. 로컬(한국) 43곳에 더해 9곳(조선대병원, 삼성창원병원, 대구의료원, 분당제생병원, 을지대병원 3곳, 광주기독병원, 라파엘신경과)이 연결 시간 초과로 지워졌다. 해외 접속을 막거나 느리게 응답하는 사이트로 보인다. 링크가 깨지지는 않고 네이버 지도로 간다.
- 디자인 리뷰: P1 1건, P2 5건. 아래 후속 작업에 넣었다.

## 후속 작업

과제 마감으로 이번 작업에서는 하지 않는다.

| 우선 | 내용 | 방향 |
|---|---|---|
| 높음 | 해외 러너에서 연결 시간 초과로 홈페이지가 잘못 지워진다 | 시간 초과는 지우지 않는다. 확실한 실패(도메인 없음, 404·410, 인증서 오류)만 지운다. 한국에서도 응답 없는 옛 대학병원 주소 몇 곳은 남는 것을 감수한다 |
| 높음 | 400 응답 홈페이지가 남는다 (V4) | 400도 죽은 링크로 본다 |
| 높음 | "아직 판단하기 일러요" 위 단계 막대가 "신호 약함"을 가리켜 제목과 반대로 읽힌다 (디자인 P1) | 판단 보류일 때 ▼와 현재 칸 강조를 빼고 세 칸을 흐리게 둔다 |
| 중간 | 판단 보류 화면의 "‘네’라고 답한 신호가 없어요"가 안심으로 읽힌다 | "잘 모르겠어요 n개"를 함께 보여준다 |
| 중간 | 지도로 가는 카드(약 48%)에서 "병원 정보 보기"와 주소가 같은 지도로 간다 | 이 카드만 버튼 이름을 "지도에서 보기"로 바꾼다 |
| 중간 | "병원 정보 보기" 버튼 hover 때 노란 글자가 크림색으로 바뀐다(데스크탑) | 선택 버튼처럼 `hover:text-primary`를 준다 |
| 중간 | 320px·글자 200%에서 주소가 어절 중간에서 끊긴다 | `overflow-wrap:anywhere` 대신 `break-keep` 계열로 어절 단위 줄바꿈 |
| 낮음 | 위치 거부 안내가 PC에서도 "휴대폰에서…"로 시작한다 | 기기에 맞춰 문구를 바꾼다 |
