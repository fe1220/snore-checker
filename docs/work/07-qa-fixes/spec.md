# 스펙: 프로덕션 QA 반영

상태: 승인

2026-10-03 프로덕션 QA([리포트](../../../.gstack/qa-reports/qa-report-snore-check-vercel-app-2026-10-03.md), 로컬 전용)에서 나온 6건을 반영한다. 항목 번호는 QA 리포트의 ISSUE 번호를 따른다.

## 범위

| 포함 | 제외 |
|---|---|
| ISSUE-001 죽은 홈페이지 링크 | 네이버 지도로 가는 심평원 병원 343곳의 원 페이지 연결 |
| ISSUE-002 "잘 모르겠어요"만 있을 때 판정 문구 + 공유 링크 v2 | 판정 단계(3단계) 추가 |
| ISSUE-003 신호 약함에서 위험·이득 카드 숨김 | 리포트 위계 변경 |
| ISSUE-004 지역 정렬 문서 갱신 | 정렬 코드 변경 |
| ISSUE-005 선택 버튼 hover 색 | 버튼 컴포넌트 variant 변경 |
| ISSUE-006 주소를 모두 지도 링크로 | 카드 버튼 구성 변경 |

## 결정

- **001 죽은 홈페이지는 크롤러가 지운다.**
  - 크롤링할 때마다 `homepage`가 있는 병원은 접속을 확인한다.
  - DNS 실패, 4xx·5xx, 연결 실패·타임아웃, 인증서 오류면 `homepage`를 `null`로 둔다. 화면은 기존 규칙대로 네이버 지도 검색으로 보낸다.
  - 일시 장애로 지우지 않게 2번 재시도한다. 확인 대상은 약 61곳이라 동시에 몇 곳씩 확인한다.
  - 크롤 로그에 지운 곳과 이유를 남긴다.
- **002 주요 신호 문항을 모르면 "아직 판단하기 일러요"로 바꾼다.**
  - 조건: 판정이 신호 약함이고, 주요 신호 3문항(숨 멈춤, 헐떡임, 운전 중 졸음) 중 "잘 모르겠어요"가 하나라도 있다.
  - 제목은 "아직 판단하기 일러요", 한 줄 설명은 "숨 멈춤은 자는 동안 지켜봐야 알 수 있어요. 며칠 밤 옆에서 본 뒤 다시 해 보세요".
  - 단계 막대는 신호 약함 그대로 두고, GA `level`도 `weak` 그대로 보낸다. 판정 규칙(`judge`)은 바꾸지 않는다.
- **002 공유 링크를 v2로 바꾸고 v1은 계속 열린다.**
  - v1은 "네"만 담아 "아니요"와 "잘 모르겠어요"를 구분하지 못한다.
  - v2는 "네"와 "잘 모르겠어요"를 둘 다 담는다(`#v2-<네>-<모름>`).
  - 새 리포트와 공유 링크는 모두 v2로 만든다.
  - v1 링크는 지금처럼 연다. "잘 모르겠어요"는 없는 것으로 본다.
  - 프로젝트 원칙은 하위 호환을 두지 않는 것이지만, 카톡으로 이미 퍼진 링크와 광고 기간 중 저장된 링크가 깨지면 안 돼서 예외로 둔다(사용자 결정).
- **003 신호 약함이면 "치료하지 않으면"과 "치료하면" 카드를 숨긴다.**
  - "자는 동안" 카드를 숨기는 기존 규칙과 같은 방식이다.
  - "검사는 이렇게 받아요"와 출처는 남긴다.
- **004 정렬은 코드가 맞다.** 지역 보기는 학회 등록 병원을 먼저 보여주고 그 안에서 주소순이다. 화면 설계 문서만 고친다.
- **005 선택된 보기 버튼은 hover 때도 노란 글자를 유지한다.**
  - 폰에서는 hover가 없어서 생기지 않는 문제다(Tailwind v4는 마우스가 있는 기기에서만 hover를 건다).
  - 데스크탑에서 클릭 직후 선택 표시가 사라져 보이는 것만 막는다.
- **006 모든 카드의 주소를 지도 링크로 통일한다.**
  - 주소 앞에 위치 아이콘, 뒤에 외부 링크 아이콘을 붙인다. 밑줄만으로는 누를 수 있다는 걸 알기 어렵다. "외부로 나가는 링크에는 외부 링크 아이콘을 붙인다"는 화면 간 일관성 규칙에도 맞춘다.
  - 터치 영역은 48px 이상, 글자는 16px으로 유지한다.
  - "병원 정보 보기"가 지도로 가는 병원은 주소와 버튼이 같은 곳으로 간다. 사용자가 이 중복을 받아들였다.

## 성공 기준

- 크롤 결과에 접속되지 않는 `homepage`가 없다. 크롤러 테스트로 확인한다.
- 주요 신호 문항을 모른다고 답하면 "걱정 신호가 적어요"가 나오지 않는다. v2 공유 링크로 열어도 같다.
- 기존 v1 링크(`#v1-e7`, `#v1-0`)가 이전과 같은 리포트를 보여준다.
- 신호 약함 리포트에 위험 막대와 치료 이득 카드가 없다.
- 모든 병원 카드의 주소가 같은 모양의 지도 링크다.
- `make gate`가 통과한다.
