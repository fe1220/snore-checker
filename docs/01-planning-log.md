# 기획 과정

문제 정의([01-problem-definition](01-problem-definition.md))에 이르기까지의 출발점과, 기획하며 검토한 질문과 결론을 기록한다.

## 출발점: 실제 사례

**아버지 → 수면무호흡, 양압기 치료**

1. 아버지는 머리만 대면 잠들었다. 본인은 익숙해서 문제로 여기지 않았다.
2. 나는 수면장애일 수 있다고 생각했다. 수면장애가 있으면 심혈관 질환 위험이 올라간다고 해서, 나이 드신 아버지 건강에 나쁜 영향이 오래 쌓일까 걱정됐다.
3. 아버지에게 검사를 받아보라고 했지만 듣지 않았다.
4. 아버지보다 설득이 쉬운 엄마에게, 아버지를 데리고 검사받으러 가달라고 했다.
5. 네이버 지도 리뷰를 보고 병원을 찾아 추천까지 해줬다.
6. 검사 후 양압기 치료를 시작했다.

**전해 들은 사례: 어머니(보험설계사)의 고객 → 수면무호흡**

1. 남성 고객의 아내가 남편을 병원에 데려갔다.
2. 아내의 동기는 남편 건강 걱정이 아니라 **코골이 소음이 너무 심해 같이 자기 힘들어서**였다.

**두 사례에서 얻은 것**

| 관찰 | 문서에 반영한 곳 |
|---|---|
| 본인은 증상에 익숙해 문제로 여기지 않았다. 의료계엔 이미 해결책(양압기)이 있었다 | 문제 진술, 5 Whys 2·3 |
| 증상을 먼저 이상하다고 본 건 옆 사람이었다 | 주 사용자 = 관찰자 |
| 배우자의 동기는 **자기 수면 피해(코골이 소음)**였다 | 문제 정의, 5 Whys 4, 가설 H6, 관계별 메시지 |
| 작성자(자녀)는 아버지 건강이 걱정됐지만, 매일 밤 피해를 겪는 건 아니었다 | 출발점으로만 다룬다. 메인 사용자는 배우자 |
| "검사받아봐"라는 말만으로는 움직이지 않았다 | 5 Whys 4 |
| 본인보다 배우자를 설득하는 게 더 쉬웠다 | 사용자를 배우자로 정한 근거 |
| 병원은 **리뷰를 보고** 골랐다 | 병원 연결 화면 |
| 병원 찾기와 추천까지 옆 사람이 했다 | 전환의 주인공 = 옆 사람, 주 지표 |

두 사례 모두 진료까지 간 건 본인 의지가 아니라 **옆 사람이 움직였기 때문**이다. 단 두 사례이므로 이는 가설의 출발점이지 근거가 아니다.

문제의식은 또 하나의 경험에서 시작됐다. 남자친구는 잠 많은 체질이라 여기다가 작성자의 권유와 예약으로 기면증 진단을 받았다. 처음엔 기면증도 범위에 넣었지만, 옆 사람이 매일 밤 피해를 겪는 구조가 아니고 비즈니스 규모가 작아 최종 범위에서 뺐다 ([범위](01-problem-definition.md#범위-코골이-그-뒤의-수면무호흡)).

## 기획 과정에서 검토한 질문

| 질문 | 결론 |
|---|---|
| 문제 후보는? (비급여 비교, 건강검진, 증상→진료과, 실손 청구) | 증상→진료과에서 출발했지만, 작성자 경험을 계기로 "치료법은 있는데 병인 줄 몰라 방치되는 문제"로 옮겼다 |
| 증상→진료과 안내는 ChatGPT로 되지 않나? | 된다. 그래서 "답"이 아니라 "질문이 생기지 않는 사람"으로 문제를 옮겼다 |
| 야간·주말 진료 vs 체질로 여기는 질환? | 야간 진료는 이미 있는 수요를 연결하는 문제라 경쟁이 많다. 후자는 없던 수요를 깨운다 |
| 누가 쓰나? | 매일 밤 코골이를 겪는 배우자·연인. 본인은 코를 곤다는 건 알지만 급할 이유가 없다 |
| 본인은 못 데려오나? | 처음엔 반전 카피("머리만 대면 5초 만에 잠드세요?")로 본인도 데려오려 했다. 사용자를 배우자로 정한 뒤, 당사자 카피는 메인 입구가 아니라 배우자 카피와 비교하는 데이터로만 쓰기로 했다(H1) |
| 수면장애는 몇 종류고, 무엇을 고르나? | ICSD-3 기준 7개 군. 처음엔 수면무호흡·기면증·렘수면행동장애 셋을 골랐다가 수면무호흡 하나로 좁혔다 |
| 기면증은 옆 사람 틀에 맞나? | 약하다. 낮 졸림은 옆 사람의 잠을 방해하지 않고, 후기에서도 본인·친구 말이 계기였다. 구조상 특발성 과다수면과 같은데 하나만 넣는 건 앞뒤가 안 맞았다 → 제외 |
| 왜 하나에 집중하나? | 비즈니스 임팩트, 배우자 동기, 크롤링 대상이 모두 수면무호흡에 모인다. 문항·카피·지표가 하나의 흐름이 된다 |
| 코골이와 수면무호흡은 같은가? | 다르다. 코골이는 질환이 아닌 증상·정상 변이이고 훨씬 흔하다. 습관성 코골이 남성의 약 5명 중 1명이 수면무호흡으로 추정된다 |
| 가족 건강 걱정과 본인(배우자) 불편 중 무엇이 동기인가? | 배우자는 자기 수면 피해가 더 클 수 있다(H6). 코골이 증상자의 절반이 각방을 쓴다. 이 동기를 쓰는 서비스·클리닉은 없다 |
| 비즈니스 임팩트가 있나? | 있다. 숨은 환자 유입이 수면 진료 시장의 병목이다 |
| 병원은 광고할 만큼 돈이 되나? 비급여보다 낮지 않나? | 비급여 진료과와 비교하면 낮다. 하지만 실제 고객인 이비인후과 의원(매출 88%가 급여, 내원당 약 3.2만 원) 기준으론 검사 1건이 내원 약 18일분인 고단가 항목이고, 수술·구강내장치 같은 비급여로도 이어진다 |
| 수면클리닉은 실제로 적은가? | 아니다. 95곳은 학회 인증 수다. 수면다원검사 실시기관은 742곳이고 대부분 동네 이비인후과다 |
| 진료 이후 병원 리텐션은? | 약하다. 양압기 장기 순응률은 약 3.8년 시점 12.2%이고, 병원은 양압기 관리 수가가 없어 수입이 첫해 검사에 몰린다. 그래서 병원은 신규 환자가 계속 필요하다 |
| 양압기 업체가 광고주일 수 있나? | 업체에게 환자 가치는 크지만, 이 서비스는 후원 없이도 진단 환자를 늘려 모든 업체가 이익을 나눠 갖는다. 중립성 때문에 줄 대가도 없어 후원 동기가 없다. 수익원에서 제외 |
| 기존 비급여 병원 연결과 무엇이 다른가? | 카테고리가 아니라 문제가 다르다. "어디로 갈까"가 아니라 "가야 하나"를 푼다 |
| 왜 수면다원검사로 연결하나? | 하지 않기로 했다. 첫 행동은 외래 진료이고 검사는 의사가 판단한다 → 목적지를 "수면 전문 진료"로 바꿨다 |
| 건강보험 적용을 알려줘야 하나? | 의원이 상담에서 알려준다. VOC에서도 비용은 장벽이 아니었다 |
| 레즈메드는 이 문제를 푸는 서비스가 맞나? | 맞다. 미진단 수면무호흡 환자 발굴이 양압기 회사의 사업 모델이다 |
| 같은 문제를 푸는 서비스가 있나? | 관찰자 문항과 중립 연결을 함께 갖춘 곳은 없다 |
| 수요를 창출하는 건가? | 새로 만드는 게 아니라 드러나지 않은 수요를 깨운다 |
| 지연형과 미치료형 중 어느 쪽인가? | 수면무호흡은 한 번도 진단받지 않은 사람이 다수(약 80% 이상)다. 둘 다 환자·병원 모두에 가치가 있다 |
| 진료받지 않는 85%가 모두 한 번도 안 간 사람인가? | 아니다. 연간 진료 인원 기준이라 진단 후 치료를 그만둔 사람도 섞여 있다. 진단 경험률(0.5%)로 보면 한 번도 진단받지 않은 사람은 환자의 약 80% 이상이다. 중단자는 범위 밖 |
| 사용자를 같은 방에서 자는 사람으로 한정하나? | 아니다. 각방을 써도 관계의 불편과 건강 걱정은 남는다. 같이 사는 배우자·연인으로 본다 |
| 앱에서 수면을 측정·진단하면? | 하지 않는다 (규제·정확도·이탈). 대신 분석 없는 관찰 기록 가이드를 넣는다 |
| "옆 사람"은 사실인가 가설인가? | 가설이다. 옆 사람이 증상을 겪는다는 건 근거가 있지만, 다음 행동이 막혀 멈춘다는 건 작성자 사례와 정성 근거뿐이다. [사실]/[추정]/[가설]을 표시하고 H1~H6에 검증 방법을 붙였다 |
| 본인과 옆 사람 중 누구를 설득해야 하나? | 미리 정하지 않는다. 두 경로를 모두 열고 세그먼트별 병원 연결률을 비교한다. 이후 사용자를 배우자로 정하면서 이 가설은 뺐다 |
| 대상을 수면무호흡에서 코골이로 넓히나? | 넓힌다. 배우자가 겪는 건 코골이고, 배우자는 진단이 아니라 소음이 끝나기를 원한다. 그냥 두면 안 되는 의학적 이유는 수면무호흡으로 유지한다. 어느 쪽이든 다음 행동은 이비인후과 상담과 수면검사로 같다 |
| 단순 코골이도 치료법이 있나? | 있지만 덜 확실하다. 구강장치는 표준 권고, 수술은 단기 효과·재발 흔함. 비급여다. 그래서 진료는 권하되 시술은 권하지 않는다 |
| 단순 코골이 수술은 과잉진료인가? | 그렇게 단정할 근거는 약하다. 정확히는 장기 효과 근거가 약하고 재발이 흔하며, 수면검사 없이 하면 수면무호흡을 놓칠 위험이 있다 |
| 배우자가 각방·귀마개로 이미 해결하고 있지 않나? | 아니다. 각방은 해결이 아니라 생활 방식을 바꿀 만큼 괴롭다는 증거다. 각방을 써도 수면무호흡은 남는다 |
| 코를 고는 본인은 모르나? | 코를 곤다는 건 안다. 모르는 건 얼마나 심한지, 숨이 멈추는지, 건강 문제일 수 있다는 것이다. 소음 피해는 배우자가 겪어 본인은 급할 이유가 없다 |
| 문제 정의를 어떻게 쓰나? | 한 문장으로 짜내지 않는다. 누가 겪나 / 무엇을 겪나 / 왜 해결되지 않나 / 왜 그냥 두면 안 되나로 풀어 쓴다. "다시 함께 자기"처럼 특정 결과를 필요로 단정하지 않는다 |
| 증상 신호(숨 멈춤·헐떡임·낮 졸림)를 알려주는 게 문제 해결인가? | 아니다. 증상 정보는 쉽게 찾을 수 있다. 비어 있는 건 "어디서, 무엇을"이라는 경로 정보와 행동의 공수다 |
| 코골이가 질환이고 치료 가능하다는 걸 대중이 아나? | 막연한 필요성은 안다(71%). 하지만 검사가 필요한 걸 모름 67%, 양압기 인지 26%. 경로를 모른다 |
| 그럼 병목은 무엇인가? | 의심해도 다음에 뭘 해야 할지 모르고(어느 과, 첫 단계, 어디서) 그 행동의 공수가 크다. 작성자 사례 둘 다 옆 사람이 병원을 찾거나 예약해준 뒤에야 진료로 이어졌다 |
| 옆 사람이 실행을 떠맡는 게 문제인가? | 아니다. 그건 움직일 동기가 있는 사람이 있다는 뜻이고, 이 서비스의 사용자가 누구인지에 대한 답이다 |
| 옆 사람이 "병원 가봐"라고 하면 가나? | 안 간다. 옆 사람이 병원을 찾아 추천하거나, 설득이 더 쉬운 배우자를 통해야 간다 → 전환의 주인공은 옆 사람이다 |
| 수면클리닉은 지금 어떻게 마케팅하나? | 전문성·편의 중심의 "병원 고르기" 마케팅이고 관찰자·배우자 유입 경로는 비어 있다. 니즈는 정황상 중상 |
