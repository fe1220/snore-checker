# 가설 검증

[problem-definition](problem-definition.md#핵심-가설)의 핵심 가설을 작은 가설로 나누고, 근거와 과제 기간 내 확인 방법을 정한다.

> **[사실]** 출처가 있는 수치·조사 결과 · **[추정]** 출처 수치로 직접 계산 · **[가설]** 작성자 경험·정성 사례에 기반해 아직 검증되지 않은 주장

근거 원자료: [evidence](research/evidence.md) · [awareness](research/awareness.md) · [voc](research/voc.md) · [competitors](research/competitors.md) · [benchmark](research/benchmark.md) · [clinic-survey](research/clinic-survey.md)

## 가설 구조

> **[가설] 배우자에게 네 가지(병일 수 있음, 치료 가능, 방치 시 위험, 구체적인 경로)를 주면, 배우자가 당사자를 병원에 데려간다.**

[어디서 막히나](problem-definition.md#어디서-막히나)의 흐름을 따라 넷으로 나눈다. H1·H2·H4는 메인 막힘(①, 배우자에게 판단 기준이 없음), H3는 보조 막힘(②, 당사자 거부)이다.

| # | 가설 | 틀리면 |
|---|---|---|
| H1 | 배우자는 코골이·숨 멈춤이 **병이고 치료된다는 걸 모른다** | ①의 원인이 아니다. 배우자 체크 결과의 메시지를 다시 본다 |
| H2 | 네 가지를 받으면 **배우자가 당사자에게 병원에 가자고 한다** | 핵심 가설이 틀린 것. 문제 정의를 다시 본다 |
| H3 | 배우자가 가자고 하면 **대부분의 당사자는 따라간다** (거부는 일부) | ②가 메인이다. 당사자 리포트를 보조가 아니라 중심으로 올린다 |
| H4 | 배우자는 자기 불편만 있을 때보다 **상대의 건강 위험이 같이 보일 때 더 움직인다** | 결과에서 건강 위험 비중을 줄이고 수면 불편 중심으로 바꾼다 |

## 가설별 근거와 확인 방법

### H1. 배우자는 병이고 치료된다는 걸 모른다

- **근거**
  - [사실] 인터뷰: 엄마는 수십 년간 술과 체중 탓으로 여겼고, 병인지·치료로 없어지는지 몰랐다. 치료 후 "코골이가 이렇게 사라질 수 있는 거였다"며 신기해했다([voc](research/voc.md#인터뷰-아버지-수면무호흡)).
  - [사실] 진료받지 않은 이유 1위 "치명적이지 않다고 봄" 54.4%(중국, 미진료 524명). 단, 당사자 응답이다.
  - [사실] 반대 근거: 수면무호흡 치료 필요성 인식 71.4%(업계 설문). "막연히 문제인 줄은 안다"일 수 있다.
  - [사실] 배우자가 판단 기준을 얻을 곳이 드물다. 학회 수면클리닉 81곳 중 배우자에게 직접 말을 거는 곳 0곳(병원당 4페이지)([clinic-survey](research/clinic-survey.md#결과)). 국내외 자가체크 17건 중 관찰자 기준 문항 1건([benchmark](research/benchmark.md#자가체크-응답자-기준)). 모른다는 직접 근거는 아니고, 알려주는 곳이 없다는 근거다.
- **틀렸다고 볼 기준:** 커뮤니티 글 대부분이 남편 코골이를 이미 병·검사로 말하는데도 병원에 안 갔다.
- **48시간 내 확인**
  - 커뮤니티 남편 코골이 글 분류: 소음·습관으로 말하는 글 vs 병·검사로 말하는 글의 비율.

### H2. 네 가지를 받으면 배우자가 움직인다 (핵심)

- **근거**
  - [사실] 인터뷰: 작성자가 엄마에게 네 가지를 알려주자 엄마가 가자고 했고, 아빠가 따라가 진단·양압기 치료까지 갔다. **1건뿐이고, 작성자 가족이다.**
  - [사실] 병원에 간 환자가 질환을 알게 된 경로 "동거인이 숨 멈춤을 알아챔" 37.6%, "코골이로 동거인 수면 방해" 25.5%(업계 설문, 274명). 배우자가 이미 가장 큰 계기다.
  - [가설] 경로(④)는 검색하면 나오지만, 인터뷰에서는 경로까지 줘야 판단이 행동으로 바뀌었다.
  - [사실] 배우자 대상 해외 사례 6건은 정보 제공·자사 상담·제품에서 끝나고, 중립 병원 목록으로 보내는 곳은 0건이다([benchmark](research/benchmark.md#교차-배우자가족에게-말을-거는-6건은-어디서-끝나나)). 네 가지를 한 흐름으로 준 사례가 없어, 이 가설은 제품 지표로만 확인할 수 있다.
- **틀렸다고 볼 기준:** 제품에서 결과를 본 배우자의 병원 링크 클릭률이 낮다.
- **확인**
  - 과제 기간에는 이벤트 기록(체크 완료 → 결과 조회 → 병원 링크 클릭)까지 만든다. 메타 광고가 돌면 초기 수치가 나온다.
  - 출시 후: **결과를 본 배우자 중 병원 외부 링크를 누른 비율(북극성 지표)**.

### H3. 배우자가 가자고 하면 대부분 따라간다

- **근거**
  - [사실] 인터뷰: 아빠는 거부하지 않았다. "엄마가 가자고 하면 따라가는 편"이었다. 부모님 사이가 워낙 좋은 집이다.
  - [사실] 반대 근거: [Reddit 남편 코골이 스레드](https://www.reddit.com/r/beyondthebump/comments/1g98hnv/husbands_snoring_is_driving_me_insane_what_to_do/)(r/beyondthebump)에서 "그냥 코골이일 뿐"이라며 검사를 거부한 사례 3건 이상(미국, 스레드 1개).
- **틀렸다고 볼 기준:** 커뮤니티 사례 중 병원 권유 여부가 글에 명시된 건에서 "권했는데 안 갔다"가 "권한 적 없다"보다 많다.
- **48시간 내 확인**
  - 커뮤니티 글 분류: 권한 적 없음 / 권했는데 거부 / 권해서 갔음.

### H4. 상대의 건강 위험이 같이 보이면 배우자가 더 움직인다

- **근거**
  - [사실] 인터뷰에서 엄마는 수십 년 소음을 참았지만, "치료하지 않으면 건강에 안 좋다"는 말을 듣고 움직였다([voc](research/voc.md#인터뷰-아버지-수면무호흡)).
- **틀렸다고 볼 기준:** 커뮤니티 글에서 병원 얘기를 꺼낸 계기가 상대 건강 걱정보다 내 잠 문제로 더 많이 나온다.
- **48시간 내 확인**
  - 커뮤니티 글 분류: 병원·검사를 언급한 글에서 계기가 건강 걱정(숨 멈춤, 졸음 운전 등)인지 내 잠(소음, 각방)인지 나눈다.

**확장 단계로 미룬 가설:** 당사자가 거부하면 거부 이유에 맞춘 리포트("난 괜찮아", "너 때문이잖아", "귀찮아")가 동의를 끌어낸다. 이번 MVP는 결과 공유 링크까지만 만들고, 공유율 데이터를 보고 정한다. 아빠가 검사도 양압기 유지도 "엄마를 위해" 한다는 반대 신호가 있어, 배우자를 위한 동기를 나쁜 메시지로 단정하지 않는다.

## 메타 광고 유입 검증

가설이 아니라 [솔루션 0단계 "닿기"](solution-direction.md#솔루션-방향)의 리스크를 본다. 배우자가 들어오지 않으면 체크·결과·병원 목록도, 병원 광고 수익도 성립하지 않는다.

> **검색하지 않는 배우자를 데려올 수 있나, 얼마에?**

- 볼 숫자: 클릭률·클릭당 비용 → 체크 완료율 → 병원 링크 클릭률 → **병원 링크 클릭 1건당 비용**.
- 광고 세트 1개에 소재 5개, 총 10만 원, 10월 2일 밤 ~ 10월 5일. 어떤 메시지가 이기는지는 보지 않는다.
- 과제 제출 시점에는 중간 숫자만 있어 초기 신호로만 본다.
- 소재와 상세 설계는 [meta-ads](meta-ads.md).

## 리스크 확인

[리스크](problem-definition.md#리스크) 중 데이터로 확인할 수 있는 것이다.

| 리스크 | 근거 | 확인 방법 |
|---|---|---|
| 진짜 병목이 비용·양압기 부담일 수 있다 | [사실] 진료받지 않은 이유 중 비용 22.5%(중국). [사실] 인터뷰에서 양압기 사용 시간을 못 채우면 대여료가 월 1만 원대 → 7만 원대로 오른다 | 커뮤니티 글에서 비용·양압기 부담 언급 비율 |
| 관계가 나쁘면 당사자가 안 간다 | [사실] 인터뷰 사례는 사이가 좋은 집이라 거부가 없었다 | H3과 같이 보고, 출시 후 결과 공유율로 본다 |
| 근거가 적다 | 인터뷰 1건, 국내 설문 1건, 해외 스레드 1개 | 커뮤니티 글 분류로 보강 |

| 방법 | 보는 가설 | 분량 |

- 실제 검사 여부는 추적할 수 없어 병원 링크 클릭을 대리 지표로 쓴다([성공 지표](problem-definition.md#성공-지표)).
- 과제 기간에는 이벤트 기록까지 만들고, 지표 수치는 출시 후 데이터로 본다.

## 커뮤니티 글 분류 계획

**진행 상태 (2026-10-03):** 멈춤. 검색 목록 945건을 받았지만 본문 17건째에서 연결이 차단됐고, 재시도도 막혔다([troubleshooting](troubleshooting.md#82cook-글-수집이-17건에서-연결-거부로-멈췄다), [agent-log](agent-log.md)). 분류 결과가 없어 H1·H3·H4와 비용 리스크는 아직 기존 근거로만 받친다.

**수집 대상: 82cook 자유게시판만 쓴다.**

| 후보 | 판단 | 이유 |
|---|---|---|
| 82cook 자유게시판 | 사용 | 로그인 없이 보이고, robots.txt가 게시판·검색을 허용하고, 정적 HTML이다. 이용자가 40~60대 여성 중심이라 사용자와 겹친다 |
| 네이버 지식인, 디시 | 제외 | robots.txt가 AI 봇과 AI 목적 접근을 금지한다. 건수(지식인 "남편 코골이" 3,782건)는 많지만 쓰지 않는다 |
| 맘카페(네이버 카페), 네이트판, 다음 카페 | 제외 | robots.txt가 전체를 금지하거나 로그인이 필요하다 |
| 뽐뿌, 클리앙 | 제외 | robots.txt가 검색 경로를 금지한다 |

- 처음 계획은 맘카페 글 20~30개였다. 맘카페는 수집할 수 없어 82cook으로 바꾸고, 대신 건수를 늘렸다.
- 요청은 1초에 1건 이하로 한다. 원문과 작성자 정보는 저장소에 남기지 않고, 집계와 뜻을 옮긴 인용만 [voc](research/voc.md)에 남긴다.

**분류 축**

표본 9건을 먼저 읽고 축을 고쳤다. 한 글에 소음 불만과 건강 걱정이 같이 나오는 경우가 많고, 병원을 권했는지는 대부분 글에 없었다.

| 축 | 값 | 보는 가설 |
|---|---|---|
| 화자 (먼저 거른다) | 배우자·연인 / 당사자 / 자녀 등 / 무관·광고 | 배우자·연인 글만 집계한다 |
| 인식 | 소음·습관으로만 말함 / 건강 걱정은 있으나 병·검사 언급 없음 / 무호흡·병·검사를 말함 / 알 수 없음 | H1 |
| 찾는 해결책 | 귀마개·각방 등 혼자 하는 대처 / 수술·기구 / 병원·검사 / 없음 | H1 |
| 병원 권유 | 언급 없음 / 권한 적 없음(명시) / 권했으나 거부·미룸 / 권해서 감 / 당사자가 스스로 감 | H3 |
| 계기 (병원을 언급한 글만, 복수) | 내 잠·소음 / 상대 건강 / 아기·가족 / 관계·각방 / 알 수 없음 | H4 |
| 비용·양압기 부담 언급 | 있음 / 없음 | 비용 리스크 |

- 82cook은 댓글에 "우리 남편도 안 간다" 같은 사례가 달린다. 댓글의 사례도 따로 센다.
- 글 하나를 서로 다른 에이전트 둘이 따로 분류하고, 갈린 건은 사람이 본다. 일치율을 함께 적는다.

**기준을 고친 것**

- H3: "권했는데 안 갔다"와 "권한 적 없다"는 **글에 명시된 건끼리만** 비교한다. "언급 없음"은 따로 세고 비교에 넣지 않는다. 언급 없음이 대부분일 것이라 H3은 약한 근거로만 쓴다.
- H1: 비율은 "남편 코골이", "신랑 코골이" 검색어로 잡힌 글로만 계산한다. "무호흡"으로 검색한 글은 이미 병으로 아는 사람이 쓴 글이라 H3·H4에만 쓴다.

**한계**

- 병원에 가서 해결된 사람은 글을 쓰지 않는다. "권해서 감"이 실제보다 적게 잡힌다.
- 82cook 한 곳이고 불만 글이 많이 모인다. 전체 배우자의 비율로 읽지 않고, 가설과 맞는 방향인지만 본다.

## 이전 버전에서 바꾼 것

- 이전 H1~H6을 핵심 가설에 맞춰 H1~H4로 줄였다.
- "당사자 카피 vs 배우자 카피"(이전 H1), "수면 불편 vs 건강 카피"(이전 H6), "각방 배우자의 의지"(이전 H5)는 뺐다. 사용자를 배우자로 정한 뒤 메시지 축이 "네 가지"로 바뀌었기 때문이다. 메타 광고는 가설 검증이 아니라 유입 검증(솔루션 0단계)으로 옮겼다. 클릭은 행동이 아니라 H4를 확정할 수 없고, 사업의 첫 관문은 배우자를 데려올 수 있느냐이기 때문이다. H4는 커뮤니티 글 분류로 본다.
- H4를 보조 막힘(②)에서 메인 막힘(①)으로 옮겼다. 당사자 거부가 아니라 배우자에게 무슨 말을 할지에 대한 가설이기 때문이다.
- "당사자가 직접 답한 자기 증상이 있어야 움직인다"(이전 H4)는 인터뷰에서 당사자가 배우자를 따라간 사례와 맞지 않아, 거부할 때만 쓰는 보조 가설로 내렸고, 이후 확장 단계로 미뤘다.
- 지인 인터뷰는 과제 기간 안에 할 수 없어 뺐다. H1·H3·H4와 비용 리스크는 커뮤니티 글 분류로, H2는 제품 지표로 본다. 사람을 직접 만나 확인하지 못한 점은 근거의 한계로 남는다.
