# 디자인패스

상태: 승인

[문제 정의](01-problem-definition.md)와 [솔루션 방향](01-solution-direction.md)을 화면으로 옮기기 전에 정보 위계, 화면 흐름, 상태별 동작을 정한다. 시각 규칙은 [DESIGN.md](../DESIGN.md)를 따른다.

## 범위

배우자가 광고로 들어와 체크하고, 리포트를 보고, 근처 수면클리닉의 원 페이지로 넘어가기까지다.

| # | 화면 | 주요 행동 (화면당 1개) | 지금 상태 |
|---|---|---|---|
| S1 | 체크 시작 | 지금 바로 3분 체크하기 | 실험용으로 배포됨. 카피별 랜딩 3개 → 1개로 합친다 |
| S2 | 체크 (9문항) | 답 고르기 | 배포됨 |
| S3 | 수면 체크 리포트 | 근처 수면클리닉 찾기 | 배포됨. 아래 구조로 다시 만든다 |
| S4 | 근처 수면클리닉 | 병원 정보 보기 (외부 링크) | 없음. 지금은 레즈메드 병원찾기로 바로 넘긴다 |
| S3' | 공유받은 리포트 | 근처 수면클리닉 찾기 | 배포됨 |

## 흐름

```
메타 광고 (utm_content=소재)
  → S1 체크 시작
  → S2 체크 9문항 (한 화면에 한 문항, 답하면 다음으로)
  → S3 리포트 ──── 리포트 보내기 → 카톡 등 공유창 → S3' 공유받은 리포트
  → S4 근처 수면클리닉
  → 병원 원 페이지 (새 탭, 외부 링크)
```

## S1 체크 시작

| 위계 | 내용 |
|---|---|
| 1 | 헤드라인 (예: "코골이가 이렇게 사라질 수 있는 거였어요?") |
| 2 | 한 줄 설명: 숨 멈춤이 있으면 치료로 나아질 수 있는 병일 수 있다 |
| 3 | 안심 포인트 3개: 옆에서 본 것만 답하면 돼요 / 검사는 건강보험이 돼요 / 근처 수면클리닉까지 알려드려요 |
| CTA | 하단 고정 "지금 바로 3분 체크하기" |

- 광고 소재는 4개지만 랜딩은 하나다. 소재 구분은 `utm_content`로 GA4에서 본다([meta-ads](01-research/meta-ads.md)).
- "진단" 대신 "체크"라고 쓴다. 의료기기 규제와 광고 심사 때문이다.

## S2 체크

- 한 화면에 한 문항, 답 세 개(네 / 아니요 / 잘 모르겠어요). 고르면 바로 다음으로 넘어간다.
- 위에 진행 막대와 "n / 9 · 옆에서 본 대로 답해 주세요", 2번 문항부터 뒤로 가기.
- 문항은 STOP-Bang 구조를 배우자 관찰용으로 바꾼 자체 문항이다. 체중 문항은 체형 평가처럼 들리지 않게 "최근 몇 년 사이 체중이 늘었어요"로 묻는다.

## S3 수면 체크 리포트

레퍼런스(NHS 케어카드, 애플워치 수면무호흡 알림, 국가건강검진 결과통보서, 23andMe, Oura·Withings, ResMed 결과 페이지)에서 공통 원칙을 가져왔다: 판정과 할 일을 한 문장으로 맨 위에, 단계는 3개로 색·문구 고정, 숫자는 기준 대비 막대로, 근거는 펼쳐서, 강조 행동은 하나.

**정보 위계 (읽는 사람의 질문 순서)**

| 순서 | 읽는 사람의 질문 | 영역 | 처리 |
|---|---|---|---|
| 0 | 이게 뭐지? | 문서 머리말: 수면 체크 리포트 · 날짜 · 배우자 관찰 9문항 | 얇은 줄, xs |
| 1 | 그래서 어떻다는 거야? | 판정: 3단계 칩(신호 약함 / 상담 권유 / 검사 권유) + 판정 문장 + 한 줄 이유 + 수면무호흡증 정의 | 카드 없이 전체 폭, 왼쪽에 단계 색 띠. 제목 2xl |
| 2 | 왜 그렇게 판단해? | 옆에서 본 신호 (9개 중 n개), 주요 신호 표시 | 카드 |
| 3 | 그냥 두면? | 치료하지 않으면: 졸음운전 사고 2.4배, 심혈관 질환(중증) 2.9배 | 카드, 기준(일반인 1) 대비 막대 + 각주 |
| 2-1 | 자는 동안 무슨 일이? | 자는 동안 이런 일이 생겨요: 숨이 멈출 때마다 깬다, 중등도면 한 시간에 15번 이상 | 카드, 노랑 강조 한 줄. 신호 약함에서는 숨긴다 |
| 4 | 고치면? | 치료하면: "잠이 달라지면 삶이 달라져요" + 본인의 영역별 한 줄 이득(잠·머리·기분·운전·관계·혈압·화장실·성기능). 수치는 운전(사고 위험 약 70% 감소)에만. 아래에 보조로 "함께 자는 사람도 더 깊이 자요" | 카드 하나. 본인 이득이 주, 함께 자는 사람은 구분선 아래 보조. 영역 이름 + 내용 2열 |
| 5 | 뭘 하면 돼? | 검사는 이렇게 받아요: 3단계, 주말 검사, 본인부담 약 12~14만 원 | 카드, 번호 단계 |
| 6 | 믿어도 돼? | 판단 기준 / 출처 (접힘), 진단 아님 한 줄 | Accordion, sm·xs |
| CTA | | 하단 고정: 근처 수면클리닉 찾기 (주요) / 리포트 보내기 (보조, ghost) | |

**판정 문구**

| 단계 | 칩 | 제목 | 띠 색 |
|---|---|---|---|
| 강한 신호 1개 이상 | 검사 권유 | 수면무호흡증 신호가 보여요. 수면검사를 권해요 | warning |
| 그 외 신호 3개 이상 | 상담 권유 | 수면무호흡증 신호가 여러 개예요. 상담을 권해요 | primary |
| 그 외 | 신호 약함 | 지금은 걱정 신호가 적어요 | 중립(border) |

**수치 원칙** (근거 검증 결과)
- 막대는 위험 쪽에만 쓴다. 심혈관 2.9배는 "남성 대상 관찰 연구"를 출처에 명시하고, 치료 쪽에는 심혈관을 넣지 않는다(SAVE 시험에서 치료 효과 미확인).
- 배우자 이득은 환산값(+62분) 대신 측정값(수면 효율 74% → 87%)을 쓰고 소규모 연구임을 밝힌다.
- 본인 이득은 "숨 멈춤 → 잠이 깨짐 → 삶 전반"으로 연결해 영역별로 넓게 보여준다. 치료 효과 메타분석이 있는 것만 넣는다: 사고 위험(Tregear 2010), 기분(Povitz 2014), 야간뇨(Wang 2015), 성기능(Clin Respir J 2021 메타분석, "나아질 수 있어요"로 약하게).
- 기억력(치료 효과가 주의력에 한정)과 체중·혈당은 치료 이득으로 쓰지 않는다.

**공유받은 리포트 (S3')**
- 같은 리포트에 판정 위로 한 줄 "당신의 낮 졸림과 피로도 이것 때문일 수 있어요"를 붙인다(신호 약함일 때는 뺀다). 리포트 보내기 버튼은 없다.
- 응답은 주소 해시에 버전과 함께 인코딩한다(`tech-stack.md`). 해시는 서버·분석 도구로 전송되지 않는다. 그래서 리포트는 클라이언트에서 그린다.
- 카톡 미리보기는 OG 이미지 하나("옆에서 본 코골이, 병원에 가볼 만할까요?")로 고정한다.

## S4 근처 수면클리닉

크롤링 필수 요건이 걸린 화면이다. 데이터는 레즈메드 병원찾기(337곳)다. 대한수면연구학회 인증 배지는 다음 단계로 미룬다(병원을 잘못 맞추면 배지가 엉뚱한 곳에 붙는다).

| 위계 | 내용 |
|---|---|
| 1 | 제목 "근처 수면클리닉" + 출처와 마지막 수집 시각 (xs, 예: 레즈메드 병원찾기 · 10월 2일 수집) |
| 2 | 보기 방식 두 버튼을 한 줄에: 지역 선택 ("전체 · 337곳", 하단 Sheet) / 내 주변 순으로 보기 |
| 3 | 병원 카드 목록: 병원명, (내 주변일 때) 거리, 주소, 전화하기 / 병원 정보 보기(외부 링크, 새 탭) |

**보기 방식**

| 방식 | 목록 | 카드 |
|---|---|---|
| 지역 (기본 "전체") | 고른 시·도, 주소 가나다순 | 거리 없음 |
| 내 주변 | 전국, 가까운 순 | 거리 표시 ("2.3km") |

- 처음에는 위치 권한을 묻지 않고 "전체"로 시작한다. 디지털 친숙도가 낮은 대상이라 들어오자마자 권한 창을 띄우지 않는다.
- 권한은 "내 주변 순으로 보기"를 눌렀을 때만 요청한다. 이유를 알고 누른 뒤라 당황하지 않는다(네이버 지도, 굿닥, 똑닥과 같은 방식).
- 지역을 고르면 지역 방식으로, 내 주변을 누르면 내 주변 방식으로 바뀐다. 둘을 조합하지 않는다. 지금 방식의 버튼에 선택 상태(`primary` 글자·테두리)를 준다.
- 지역 Sheet에는 병원이 있는 시·도만 건수와 함께 보여준다("서울 81").
- 목록은 나누지 않고 전부 보여준다. "더 보기"나 페이지 번호를 두지 않는다. 스크롤이 가장 익숙한 동작이고, 필요한 병원은 지역 선택과 거리 순으로 위에 오게 한다.
- 위치는 브라우저 안에서 거리 계산에만 쓰고 저장·전송하지 않는다.

**카드**

- 카드 전체를 링크로 만들지 않는다. 카드 안에 전화하기와 병원 정보 보기 버튼 두 개를 둔다.
- 두 버튼 모두 `outline`이다. 주요 행동인 병원 정보 보기만 `primary` 글자·테두리로 강조한다. 카드마다 노랑으로 채운 버튼을 두면 화면에 주요 버튼이 수십 개가 된다.
- 이 화면에는 하단 고정 바를 두지 않는다. 화면 전체에 하나뿐인 행동이 없다.

**뺀 것**

- 주말 검사 안내: 리포트의 "검사는 이렇게 받아요"와 겹치고, 어느 병원이 되는지 데이터가 없어 숙제만 준다.
- 병원 광고(상단 노출 + "광고" 표시): 수익 모델에 있지만 MVP에는 자리를 만들지 않는다.

## 상태

| 화면 | 로딩 | 빈 상태 | 에러 |
|---|---|---|---|
| S3 | 클라이언트에서 해시를 읽는 동안 리포트 모양 Skeleton | - | 해시가 없거나 잘못됨: "리포트를 찾을 수 없어요" + 다시 체크하기 |
| S4 | 정적 생성이라 없음 | 선택한 지역에 병원 없음: 아이콘 + "이 지역에는 아직 등록된 곳이 없어요" + 전체 보기 | 데이터 파일이 비었을 때: 레즈메드 병원찾기 외부 링크로 대체 |
| S4 위치 | 확인 중: 버튼 비활성 + "위치 확인 중…", 목록은 그대로 | - | 권한 거부: "위치 권한이 꺼져 있어요. 지역을 골라 주세요" / 그 외 실패: "위치를 확인할 수 없어요. 지역을 골라 주세요". 버튼 아래에 보여주고 지역 방식을 유지 |

## 화면 간 일관성

- 판정 단계 이름(신호 약함 / 상담 권유 / 검사 권유)은 칩, 제목, 판단 기준에서 같은 말을 쓴다.
- 주요 버튼은 모두 하단 고정 바, 전체 폭, `h-12`. (S4는 고정 바가 없다)
- 외부로 나가는 링크에는 모두 외부 링크 아이콘을 붙인다. 리포트의 "근처 수면클리닉 찾기"는 이제 서비스 안의 S4로 가므로 아이콘을 뺀다.

## 모바일 / 데스크탑

375px 기준으로 설계한다. 데스크탑은 `max-w-screen-md` 가운데 정렬로 늘리기만 하고 배치를 바꾸지 않는다. 유입이 모바일 광고라서다.

## 리스크

| 리스크 | 대응 |
|---|---|
| 리포트의 위험 수치가 공포 마케팅처럼 읽힌다 | 기준 대비 막대와 출처, 연구 성격을 함께 보여주고 경고색은 막대 하나에만 쓴다 |
| 해시 기반 리포트라 서버 렌더링이 안 되고 첫 화면이 늦다 | 리포트 모양 Skeleton으로 빈 화면을 막는다 |
| 지역 필터만으로는 "가까운 곳"을 찾기 어렵다 | 내 주변 순으로 보기를 함께 둔다. 시·군·구 선택은 확장 단계로 둔다 |
| 메타 광고의 인앱 브라우저에서 위치 요청이 막힐 수 있다 | 실패 안내를 보여주고 지역 선택으로 계속 쓸 수 있게 한다 |

## 확인 필요

1. 공유 링크를 경로 코드(`/r/dh`)에서 해시(`#v1-dh`)로 바꾸는 것 (`tech-stack.md`에 맞춤)
2. 분석을 Vercel 웹 분석에서 GA4로 바꾸는 것 (GA4 측정 ID 필요)
3. 랜딩을 카피별 3개에서 1개로 합치고 소재는 `utm_content`로 보는 것 (`meta-ads.md`에 맞춤)
4. S4 지역 선택을 시·도 단위로 시작하는 것
