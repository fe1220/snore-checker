확정은 `architecture`에서 한다.

## 제외

- 하이닥: www 접속 타임아웃/502, `Python-urllib`·`HeadlessChrome` 차단.
- 네이버 지식iN: Q&A 상세 경로 차단, AI·RAG 사용 명시적 금지.
- 똑닥: 규칙 모호, JS 렌더링.
- 대한수면의학회 병원 목록: AJAX, 내부 API 미확인.

## 메모

- 낮잠 검사(MSLT), 비디오 수면다원검사 여부 필드는 두 곳 모두 없다. 목적지가 "수면 전문 진료"라 문제없다(검사 종류는 진료 의사가 판단).
- 레즈메드는 수면 자가테스트·블로그·수면다원검사 병원찾기를 직접 운영해 의심하는 사람을 검사로 잇는다 → "같은 문제를 푸는 서비스" 요건에 맞는다.
- 데이터 구성 초안: 레즈메드(기본, 위치·상세 링크) + sleepnet(학회 인증 배지 보강).
