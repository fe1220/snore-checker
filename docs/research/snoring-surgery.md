# 단순 코골이 수술 근거

조사일 2026-10-01.

## 결론

"과잉진료 논란"은 근거가 약한 표현이다. 더 정확하게는:
**단순 코골이 수술은 장기 효과 근거가 약하고 재발이 흔하며, 수면검사 없이 하면 수면무호흡을 놓치거나 악화시킬 위험이 있다. 비급여라 가격 편차가 크고 환자가 비교하기 어렵다.**

## 근거

| 내용 | 출처 |
|---|---|
| 구개 수술이 다른 치료보다 낫다는 근거 없음, 6~8주 주관적 개선은 있으나 2년 이상 지속 근거 없음, 지속 부작용 최대 58~59% → 단순 코골이 구개 수술 routine 비지원 | NHS Evidence-Based Interventions 2019 https://ebi.aomrc.org.uk/interventions/snoring-surgery-in-the-absence-of-obstructive-sleep-apnoea/ |
| 고주파(RFA) 장기 추적(평균 6.3년): 침상 파트너 92.7%가 재발 보고 | De Kermadec 2014 https://www.sciencedirect.com/science/article/pii/S1879729613001117 |
| LAUP는 수면호흡장애 치료로 비권고, **수술 전 수면다원검사 등으로 수면호흡장애 평가 필수** | AASM 2001 https://pubmed.ncbi.nlm.nih.gov/11480657/ |
| 수면무호흡 환자에게 LAUP 시 44%가 AHI 악화 | Camacho 2017 메타분석 https://pubmed.ncbi.nlm.nih.gov/28201808/ |
| 같은 코골이 수술 비급여가 100만 / 650만 / 867만 원 (2013 국감) | 메디칼업저버 2013-10-15 http://www.monews.co.kr/news/articleView.html?idxno=61094 |
| 대한이비인후과학회 일반인 안내: 수면다원검사로 진단, 수술은 신중해야 하고 개선되지 않는 경우도 드물지 않음 | https://www.korl.or.kr/info/sub02_05.php |
| 구강장치: 단순 코골이에 "무치료보다 구강장치" STANDARD 권고 | AASM/AADSM 2015 https://aasm.org/resources/clinicalguidelines/oral_appliance-osa.pdf |

## 반대 근거

- 독일 S3(2019): 연구개가 원인이면 수술 제안 가능(RFA·LAUP 1b/A). 단 RFA는 1.5년 후 코골이 재증가. https://pmc.ncbi.nlm.nih.gov/articles/PMC6947688/
- NICE IPG476(2014): RFA 단기 효능 근거 충분, 시행 가능. https://www.nice.org.uk/guidance/ipg476
- Terryn 2015(n=224): 수면검사 후 배정 시 수술·구강장치 성공률 67%로 같음. https://pubmed.ncbi.nlm.nih.gov/26921405/

## 미확인

- 국내 코골이 수술 과장광고 적발, 소비자원 피해 통계, 학회 공식 성명.
