## 한계

- **레즈메드 목록은 전체 검사기관이 아니다.** 레즈메드와 연계된 병원만 실린다. `business-impact.md`의 전국 실시기관 742곳 대비 337곳(45%)이므로, "0곳"은 "레즈메드 목록상 0곳"이고 실제 공백은 이보다 작다. 방향(군·경북·강원·전남 편중)은 유효하지만 절대값을 "검사 불가 지역"으로 쓰면 안 된다. 심평원 기관 목록으로 재검증이 필요하다.
- [추정] 인천은 2026-07 개편(제물포·영종·서해·검단구)이 인구에 반영됐는데 병원 주소는 옛 "서구·중구" 표기다. 7곳을 도로명 기준으로 수동 배정했다(서해 3, 검단 2, 제물포 1, 영종 1).
- [추정] 거리는 2018년 경계의 면적 중심(인구 중심 아님)에서 잰 직선거리다. 도로 거리·이동 시간이 아니다. 인천 신설 4개 구는 2018 경계에 없어 거리 계산에서 빠졌다(4곳 모두 병원 있음).
- hospitals.json 좌표 이상치 2곳(주소지 중심에서 40km 초과)은 거리 계산에서 제외했다: 봄봄이비인후과의원(고양 주소, 좌표는 수원 부근), 코앤365이비인후과의원(양주 주소, 좌표는 평택 부근). 프론트 거리순 정렬에도 영향을 주는 데이터 오류다.
- 주소 파싱 실패 0건(인천 7건 수동, "대한민국" 접두 1건 정규화). 목록은 `unparsed_or_flagged.csv`.
- 광주·전남은 인구통계에서 "전남광주통합특별시"로 합쳐져 있어, 옛 광주 5개 구와 옛 전남 22개 시·군으로 나눠 표기했다.

## 심평원 전체 목록으로 다시 계산 (2026-10-03)

위 한계("레즈메드 목록은 전체 검사기관이 아니다")를 확인하려고 심평원 특수운영기관 정보의 수면다원검사 실시기관 목록(743곳)을 받아 다시 계산했다. 레즈메드 337곳과 전화번호, 주소+이름으로 맞추면 양쪽에 다 있는 곳이 326곳, 심평원에만 있는 곳이 417곳, 레즈메드에만 있는 곳이 11곳이다(합 754곳).

- [확인] 구미, 경기 광주, 도봉구 등 26곳(482만 명)이 새로 채워진다. 군 지역은 거의 그대로다.
- **읽는 법:** 지금 서비스의 병원 목록(레즈메드)으로는 사용자 5명 중 1명이 자기 시·군·구에서 병원을 못 찾는다. 전체 검사기관을 다 넣어도 10명 중 1명은 여전히 못 찾는다. 앞쪽 차이는 데이터로 메울 수 있고, 뒤쪽은 실제 공급 공백이다.
- 시·도별, 시·군·구별 표: `sido-with-hira.csv`, `sigungu-with-hira.csv`.

**제품에 바로 넣지 않은 이유**

- 심평원 목록에는 좌표가 없다. "내 주변 순으로 보기"에 넣으려면 좌표를 따로 붙여야 한다.
- 이 목록 페이지에는 공공누리 표시가 없고, 심평원 저작권정책은 표시가 없는 자료는 담당자와 먼저 협의하라고 한다. 분석에는 썼지만 서비스 데이터로 싣는 것은 확인이 필요하다.
- 심평원에만 있는 417곳 중 홈페이지가 있는 곳은 59곳이다. 병원 카드의 외부 링크를 걸 곳이 마땅치 않다.
- 전화번호가 같지만 다른 기관인 경우가 1건 있었다. 전화번호만으로 합치면 안 된다.
