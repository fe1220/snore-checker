# 코드 리뷰 (2026-10-03)

시니어 엔지니어 관점에서 코드베이스 전체를 리뷰했다. 체크·결과·공유 화면도 제품 코드와 같은 기준으로 봤다. 아직 커밋하지 않은 변경(04-clinic-card, 05-meta-report)도 포함했다.

## 기준

| 관점 | 판단 기준 |
|---|---|
| 정확성 | 판정·공유 해시·매칭·병합이 경계값과 잘못된 입력에서도 맞게 동작하는가 |
| 데이터 파이프라인 | 일부만 실패했을 때 잘못된 데이터가 조용히 배포되지 않는가, 결과가 매번 같게 나오는가 |
| 아키텍처 | 레이어 규칙과 서버/클라이언트 분리가 지켜지는가 |
| 단순성 | 과한 추상화, 쓰지 않는 코드, 규칙·문구 중복이 없는가 |
| 프라이버시·보안 | 답이 저장·전송되지 않는가, XSS나 외부 링크 문제가 없는가 |
| UX 완성도 | 상태 화면, 접근성, 모바일, DESIGN.md 준수, 원 페이지 링크 |
| 테스트 | 테스트가 핵심 규칙을 실제로 지키는가 |
| 운영 | CI 게이트, 정기 크롤 실패 감지, 배포 |

심각도: 🔴 반드시 고칠 것 / 🟡 고치는 게 좋음 / ⚪ 사소함

## 총평

레이어 경계, 개인정보 설계(해시 공유, GA에서 해시 제거, 해시가 있으면 Meta 픽셀 차단), 크롤러 저장 직전 검증(임시 파일에 쓴 뒤 교체, `assertValid`)이 탄탄하다. 문제는 두 갈래다.

### 데이터 파이프라인·운영

**P1. 이전 데이터와 비교하는 가드가 없다** (`crawler/src/index.ts:25,53`)

- 레즈메드가 40% 줄어도 통과한다. 합친 결과 600건 하한은 공공데이터 스냅샷(735건)만으로 넘기 때문에 의미가 없다.
- 빠진 병원은 스냅샷 데이터로 대체된다. 그래서 목록에는 남지만 **원 페이지 링크만 조용히 사라진다**.
- 수정: 기존 JSON과 비교해 N% 넘게 줄면 중단한다.

**P2. `crawledAt` 때문에 데이터가 같아도 매주 커밋·재배포된다** (`index.ts:58`)

- "변경 없음" 분기가 사실상 실행되지 않는다.
- 수정: `items`가 같으면 쓰기를 건너뛴다.

**P3. 학회 목록 페이지 수 `PAGES = 5`가 고정값이다** (`sleepnet.ts:6`)

- 6쪽으로 늘면 뒤쪽이 잘리고, 4쪽으로 줄면 R2 경로를 탄다.
- 수정: 빈 페이지가 나올 때까지 순회하고, 안전 상한을 둔다.

**P4. 요청에 재시도와 타임아웃이 없다** (`crawler/src/http.ts:12`)

- 요청이 한 번만 실패해도 그 주 갱신이 통째로 실패한다. 응답이 멈추면 최대 15분까지 대기한다.
- 수정: 5xx 응답에만 2~3회 재시도하고, `AbortSignal.timeout(30_000)`을 건다.

**P5. 정기 크롤 실패 알림이 없다** (`crawl.yml`)

- 실패가 몇 주 이어져도 화면의 수집일만 멈춰 있어 알아채기 어렵다.
- 수정: `if: failure()`일 때 `gh issue create`로 이슈를 만든다.

**P6. 출력 순서가 레즈메드 페이지 순서를 따른다** (`merge.ts:157,183`)

- 수정: `id` 기준으로 정렬한 뒤 저장한다.

**P7. 크롤 커밋이 push 경합에 약하다** (`crawl.yml:42`)

- 크롤이 도는 동안 사람이 `main`에 push하면 크롤 쪽 push가 실패한다.
- 수정: push 전에 `git pull --rebase`를 한다.

**P8. 크롤러 출처 중 한쪽 시·도 값이 결국 버려진다** (`crawler/src/sources/resmed.ts:21-39,76-80`)

- 지역번호는 덮어쓰기 전의 region으로 붙인다. 그래서 주소와 시·도가 다른 병원은 지역번호가 틀릴 수 있다.
- 수정: resmed에서는 region을 빼고, merge에서 주소 기준으로 지역번호를 붙인다.

**P9. `kind` 값을 아무도 검사하지 않는다** (`merge.ts:236-253`, `frontend/src/lib/hospitals.ts:90`)

## 잘한 점

- **개인정보 설계가 여러 겹으로 되어 있다.**
  - 답은 해시에 비트 코드로만 담는다.
  - GA `page_location`을 직접 만들어 해시를 뺀다.
  - 주소에 해시가 있으면 Meta 픽셀을 부르지 않는다.
  - OG 이미지는 고정 이미지다.
- **레이어 경계가 실제로 지켜진다.**
  - `lib`는 React와 Next에 의존하지 않는다.
  - `hospitals.json`이 클라이언트 번들에 들어가지 않는 것을 빌드 결과로 확인했다.
- **크롤러 저장 직전 검증과 보수적인 매칭.**
  - 임시 파일에 쓴 뒤 rename으로 교체하고, `assertValid`로 검사한다.
  - 후보가 하나일 때만 매칭하고, 애매하면 합치지 않고 로그만 남긴다.
- **상태 화면이 갖춰져 있다.** 리포트 로딩과 잘못된 링크, 빈 지역, 위치 오류, error 화면, not-found 화면이 모두 있다.
- **테스트가 실제 데이터 오류 사례를 규칙 단위로 지킨다.** 통합특별시, 같은 전화번호 등이 그 예다.
