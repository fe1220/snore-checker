## 설계 원본: 사람이 직접 한 일

작성자가 엄마에게 네 가지를 알려주자 엄마가 움직였고, 아빠는 따라가 진단과 양압기 치료까지 갔다([출발점](problem-definition.md#출발점-사람이-직접-해서-성공한-사례), [VOC 인터뷰](research/voc.md#인터뷰-아버지-수면무호흡)). 서비스는 이 네 가지를 그대로 화면으로 옮긴다.

| 작성자가 엄마에게 준 것 | 서비스에서 맡는 곳 |
|---|---|
| 병일 수 있다 | 배우자 체크 결과 |
| 치료가 가능하다 | 배우자 체크 결과 |
| 치료하지 않으면 건강에 안 좋다 | 배우자 체크 결과 |
| 어느 병원에서 어떻게 예약·검사받으면 된다 | 근처 수면클리닉 목록 |

## 핵심 가설

> **[가설] 배우자에게 네 가지(병일 수 있음, 치료 가능, 방치 시 위험, 구체적인 경로)를 주면, 배우자가 당사자를 병원에 데려간다.**

경로(네 번째)는 검색하면 찾을 수 있다. 하지만 인터뷰에서는 경로까지 줘야 판단이 행동으로 바뀌었다. 그래서 원인이 아니라 **판단을 행동으로 바꾸는 마지막 단계**로 둔다.

당사자 거부(②)는 이번 MVP에서 결과 공유 링크로만 대응한다. 인터뷰에서 거부가 없었고, 두 사람의 상태를 잇는 저장 구조가 48시간 범위에 비해 크기 때문이다.

## 장벽과 대응

VOC에서 비용은 장벽이 아니었다. 검사 본인부담 12~14만 원대를 "생각보다 싸다"고 느꼈고, 비용 때문에 망설였다는 진술은 없었다([voc](research/voc.md)).

| 장벽 | 근거 | 대응 |
|---|---|---|
| **배우자가 병인지 모른다** (메인) | 엄마는 수십 년을 술과 체중 탓으로 여겼다 | 배우자가 본 것으로 수면무호흡 신호가 있는지 정리한다 |
| **치료되는지, 방치하면 어떤지 모른다** (메인) | 엄마는 치료 후 "코골이가 이렇게 사라질 수 있는 거였다"며 놀랐다 | 결과에서 치료 가능성과 방치 시 위험을 같이 보여준다 |
| **어디로 어떻게 가는지 모른다** (메인) | 검색하면 나오지만, 인터뷰에서는 경로까지 줘야 행동으로 바뀌었다 | 근처 수면클리닉과 검사 받는 법을 붙인다 |
| 당사자가 거부한다 (보조) | "치명적이지 않다고 봄" 54.4%, 인터뷰 사례에서는 거부 없음 | 결과 공유 링크 (거부 이유별 리포트는 확장 단계) |
| 하룻밤 검사 부담 | 하룻밤 센서 부담으로 거절한 사례 | 첫 방문은 외래 진료이고, 하룻밤 검사는 그다음이라는 과정을 미리 보여준다 |
| 병원 상업성 불신 | 병원의 수면용품 홍보를 보고 결과까지 의심 | 체크 결과는 병원 광고 없이 중립으로 둔다. 병원 목록은 경로를 알려주는 게 목적이라 "광고" 표시 후 광고를 넣는다 |

## 솔루션 방향

> **배우자에게 판단 기준과 경로를 준다.** 배우자가 체크하고 결과를 보고 근처 병원을 찾는다. 결과는 당사자에게 링크로 공유할 수 있다.

| 단계 | 하는 일 | 대응하는 막힌 지점 |
|---|---|---|
| 0. 닿기 | 40~60대 배우자에게 수면 불편으로 말을 건다 | 도달의 문제 |
| 1. 배우자 체크와 결과 | 본 것을 답하면 병일 수 있는지, 치료되는지, 방치하면 어떤지 보여준다 | ① 판단 기준이 없다 |
| 2. 근처 수면클리닉 | 병원 목록과 검사 받는 법, 원 페이지 외부 링크 | ① 경로가 없다 (판단을 행동으로 바꾸는 마지막 단계) |
| 3. 결과 공유 링크 (보조) | 배우자가 결과를 카카오톡으로 당사자에게 보낸다 | ② 당사자가 거부한다 |

**0. 닿기 (유입)**
- 검색하지 않는 배우자를 데려올 수 있는지, 얼마에 데려오는지는 메타 광고로 처음 확인한다([meta-ads](meta-ads/strategy.md)).
- 유입이 1순위 리스크다. 한국에서 검색하지 않는 배우자를 광고로 데려올 수 있는지 보여주는 공개 자료는 찾지 못했다.

**1. 배우자 체크와 결과**
- 문항은 배우자가 직접 본 것만 묻는다. 코골이, 숨 멈춤, 컥 하는 소리, 옆에서 본 낮 졸림.
  - [사실] 이게 빈 자리다. 국내외 서비스의 자가체크 17건 중 관찰자 기준 문항은 1건(일본 병원 공지)이다. 레즈메드처럼 "배우자·가족" 선택지를 둬도 문항은 본인 기준이다([benchmark](research/benchmark.md#자가체크-응답자-기준)). 국내 학회 수면클리닉은 자가진단이 있는 5곳 모두 성인 배우자 문항이 없다([clinic-survey](research/clinic-survey.md#결과)).
- 결과는 진단이 아니라 세 가지 판단 기준이다. 병일 수 있다 / 치료로 나아진다 / 방치하면 건강에 안 좋다.
- **방치 시 위험과 치료 시 이득을 함께 넣는다.** 배우자는 자기 불편만 있을 때보다 상대의 건강 위험이 같이 보일 때 더 움직인다 [가설]. 인터뷰에서 엄마도 "건강에 안 좋다"는 말에 움직였다.
- 치료를 과장하지 않는다. 양압기는 쓰는 동안 효과가 확실하지만 오래 쓰는 사람은 적고, 경증은 구강장치·체중 감량 같은 방법도 있다. 어느 쪽이 맞는지는 진료로 정한다.
- 신호가 약해도 상담은 선택지로 남긴다. 시술은 권하지 않는다.
- 검증 척도(STOP-Bang, ESS 등)는 상업 사용에 라이선스가 필요하므로, 판단 기준을 참고한 자체 문항을 만들고 참고 출처를 밝힌다.

**2. 근처 수면클리닉 목록**
- 레즈메드 병원찾기를 크롤링한 데이터에 심평원 공공 데이터의 검사기관과 대한수면연구학회 표시를 더해 근처 병원을 보여주고, 원 페이지로 가는 외부 링크를 단다.
- [사실] 배우자에게 말을 거는 해외 사례 6건은 정보 제공 2, 자사 상담 3, 제품 구매 1로 끝난다. 중립 병원 목록으로 보내는 곳은 0건이다([benchmark](research/benchmark.md#교차-배우자가족에게-말을-거는-6건은-어디서-끝나나)). 이 목록이 차별점이다.
- [사실] 레즈메드 목록만으로는 230개 시·군·구 중 124곳에 병원이 0곳이다(인구 20.4%). 심평원 공공 데이터의 검사기관으로 넓히면 98곳, 11.0%로 준다([supply-gap](research/supply-gap/README.md#심평원-전체-목록으로-다시-계산-2026-10-03)). 상세는 `docs/work/03-clinic-data/spec.md`.
- 검사 받는 법을 붙인다. 예약(병원 전화·홈페이지, 크롤링한 연락처로 연결), 비용([사실] 검사 본인부담 약 12~14만 원), 과정(외래 진료 → 의사 판단 → 하룻밤 검사).
- 예약은 하지 않는다. 외부 링크로 넘긴다.
- **이 화면의 외부 링크 클릭이 북극성 지표다.**

**3. 결과 공유 링크 (보조)**
- 배우자가 결과 화면에서 "카톡으로 보내기"를 누르면 당사자가 같은 결과를 받아본다.
- 맨 위에 당사자용 한 줄만 붙인다(예: "요즘 낮에 졸리고 피곤했다면, 수면무호흡증 때문일 수 있어요"). 당사자는 자기 숨 멈춤을 본 적이 없어서, 배우자가 답한 관찰이 근거가 된다.
- 별도 저장 없이 링크 공유만 한다.
- **확장 단계:** 거부 이유별 리포트("난 괜찮아", "너 때문이잖아", "귀찮아"), "가볼게" 동의 버튼, 배우자 알림. 배우자를 위한 동기를 나쁜 것으로 보지 않는다(인터뷰에서 아빠는 검사도 치료 유지도 "엄마를 위해" 했다).

## 만들지 않을 것

| 항목 | 이유 |
|---|---|
| 진단, 녹음 기반 무호흡 탐지 | 의료기기 규제, 48시간 안에 정확도를 보장할 수 없음 |
| 예약 기능 | 병원 외부 링크로 넘긴다. 예약 건당 수수료는 의료법상 환자 알선이라 불가 |
| 병원 리뷰 표시 | 크롤링 데이터에 리뷰가 없다 |
| 시술 추천 | 진료와 수면검사가 먼저다. 시술은 의사가 정한다 |
| 거부 이유별 당사자 리포트, "가볼게" 동의·알림 | 확장 단계. 인터뷰에서 거부가 없었고, 저장 구조가 48시간 범위에 비해 크다 |
| 양압기 사용 관리 | 병원 연결에서 끝난다. 치료 이후 문제는 후속 과제다([VOC](research/voc.md#인터뷰-아버지-수면무호흡)) |

## 성공 지표

| 단계 | 지표 |
|---|---|
| 배우자 유입 | 체크 완료율 |
| **배우자 행동** | **결과를 본 배우자 중 병원에 연결된 비율: 병원 외부 링크 클릭 또는 전화 걸기 (북극성 지표)** |
| 배우자 행동 (내역) | 링크 클릭과 전화 걸기를 따로 본다. 전화 걸기가 예약에 더 가까운 신호다 |
| 당사자 전달 (보조) | 결과 공유율 |

실제 검사를 받았는지는 추적할 수 없어서 병원 연결(링크 클릭과 전화 걸기)을 대리 지표로 쓴다. 클릭이 방문으로 이어졌는지는 출시 후 병원 제휴 데이터로 확인한다.

## 리스크

| 리스크 | 대응 |
|---|---|
| 관계가 나쁘면 배우자가 가자고 해도 당사자가 안 간다 | 이번엔 결과 공유 링크로만 대응한다. 거부 이유별 리포트는 확장 단계에서 공유율 데이터를 보고 정한다 |
| 진짜 병목이 비용·양압기 부담일 수 있다 | 커뮤니티 글 분류에서 확인한다 |
| 배우자 행동 근거가 적다(인터뷰 1건, 업계 설문 1건, 해외 스레드 1개) | 커뮤니티 글 분류로 보강한다 ([가설 검증](validation.md)) |
| 자가체크가 진단처럼 보일 수 있다 | "진단이 아닌 진료 권유" 문구를 원칙으로 둔다 |

## 크롤링 요구사항 대응

과제 요구사항: 정의한 문제를 풀고 있는 다른 서비스의 실제 상품·콘텐츠를 크롤링해, 해당 페이지로 이동하는 외부 링크를 제공한다 ([원문](assignment.pdf)).

| 대상 | 역할 | "같은 문제를 푸는 서비스"인가 |
|---|---|---|
| 레즈메드 수면다원검사 병원찾기 (337곳, 병원별 상세 페이지) | 기본 병원 데이터, 외부 링크 | 그렇다. 수면 자가테스트와 수면다원검사 병원찾기를 직접 운영해, 의심하는 사람을 검사로 잇는다([competitors](research/competitors.md)) |
| 대한수면연구학회 수면클리닉 찾기 (95곳, 병원 홈페이지) | 학회 인증 배지로 신뢰도 보강 | 그렇다. 학회가 수면클리닉 연결을 직접 제공한다 |
| 심평원 병의원 공공 데이터 (수면다원검사 실시기관) | 레즈메드에 없는 검사기관을 채워 공급 공백을 줄인다 | 아니다. 크롤링 요구 대상이 아니라 병원 목록 보강용 공공 데이터다 |

크롤링한 두 곳 모두 robots.txt가 해당 경로를 허용하고 정적 HTML이다. 최종 구성은 [architecture](architecture.md)에 있다 ([crawl-targets](research/crawl-targets.md)).
