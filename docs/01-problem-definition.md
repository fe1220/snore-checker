# 문제 정의

> **사실:** 수면무호흡·기면증·렘수면행동장애는 치료법이 있는데도 진료받는 사람이 적고 진단이 수년~10년 늦다. 본인이 병으로 인식하지 못하는 것이 주된 이유다.
> **가설:** 증상을 먼저 알아채는 건 함께 사는 가족이고, 진료까지 이끄는 실행도 가족이 떠맡는다. 그런데 이를 도울 근거도 도구도 없다.
> 우리는 이 가설 위에서 **옆 사람이 알아챈 신호를 수면 전문 진료로 잇는 서비스**를 만들고, 출시 후 지표로 가설을 검증한다.
>
> 이 문서는 주장마다 성격을 구분한다. **[사실]** 출처가 있는 수치·조사 결과 · **[추정]** 출처 수치를 조합한 직접 계산 · **[가설]** 작성자 경험·정성 사례에 기반해 아직 검증되지 않은 주장

## 과제 원문 요약

- 의료/헬스케어 도메인에서 비즈니스 임팩트가 있는 문제를 자유롭게 정의하고 해결 서비스를 만든다.
- 같은 문제를 푸는 다른 서비스의 실제 상품·콘텐츠를 **크롤링**해 해당 페이지로 가는 외부 링크를 제공해야 한다.
- 48시간 내 제출. 레포에 배포 링크, 문제 정의·기획 과정, 트러블슈팅 기록을 남긴다.

## 출발점: 실제 사례

작성자가 직접 겪은 두 번의 과정이 이 문제 정의의 출발점이다.

**아버지 → 수면무호흡, 양압기 치료**

1. 아버지는 머리만 대면 잠들었다. 본인은 익숙해서 문제로 여기지 않았다.
2. 나는 수면장애일 수 있다고 생각했다. 수면장애가 있으면 심혈관 질환 위험이 올라간다고 해서, 나이 드신 아버지 건강에 나쁜 영향이 오래 쌓일까 걱정됐다.
3. 아버지에게 검사를 받아보라고 했지만 듣지 않았다.
4. 엄마에게 아버지를 데리고 검사받으러 가달라고 했다.
5. 네이버 지도 리뷰를 보고 병원을 찾아 추천까지 해줬다.
6. 검사 후 양압기 치료를 시작했다.

**남자친구 → 기면증 진단**

1. 남자친구가 잠을 너무 많이 자는 것 같았다. 본인은 잠이 많고 체력이 약한 체질이라고 여겼다.
2. 뭔가 문제가 있어 수면의 질이 떨어지는 게 아닐까 싶어 수면다원검사를 제안했다.
3. 내가 병원을 예약했다.
4. 검사 후 기면증 진단을 받았고, 약을 먹은 뒤 증상이 좋아졌다.

**두 과정에서 얻은 것**

| 관찰 | 문서에 반영한 곳 |
|---|---|
| 본인은 증상에 익숙해 문제로 여기지 않았다. 의료계엔 이미 해결책이 있었다 | 문제 진술, 5 Whys 2·3 |
| 증상을 먼저 이상하다고 본 건 옆 사람(나)이었다 | 주 사용자 = 관찰자 |
| 옆 사람의 동기는 "장기적으로 건강이 나빠질까" 하는 걱정이었다 | 관찰자 니즈, 결과 화면 메시지 |
| "검사받아봐"라는 말만으로는 움직이지 않았다 | 5 Whys 4 |
| 본인(아빠)보다 배우자(엄마)를 설득하는 게 더 쉽다고 판단했다 | 공유 대상: 본인 + 배우자, 가설 H4 |
| 병원은 **리뷰를 보고** 골랐다 | 병원 연결 화면, 병원 리뷰 자산과의 연결 |
| 병원 찾기와 예약까지 옆 사람이 했다 | 전환의 주인공 = 옆 사람, 주 지표 |
| 같은 "과다 졸림" 신호가 한 명은 수면무호흡, 한 명은 기면증이었다 | 질환을 묶어서 다루는 근거, 반전 카피 |

두 사례에서 진료까지 간 건 본인 의지가 아니라 **옆 사람이 병원을 찾고 예약까지 해줬기 때문**이다. 단 두 사례이므로 이는 가설의 출발점이지 근거가 아니다.

## 5 Whys

1. **왜 치료법이 있는데 치료를 못 받나?** → 진료를 받으러 가지 않는다.
   - [추정] 수면무호흡은 환자의 약 15%, RBD는 최대 약 12%만 진료받는다.
   - [사실] 기면증은 진단까지 평균 10~11년 걸린다.
2. **왜 진료를 받지 않나?** → 본인이 병이라고 생각하지 않는다.
   - [사실] 기면증 진단 지연 이유 1위는 "질환 인지 부족"(74.6%), RBD는 "심각하지 않다고 생각"(59%).
   - [사실] 국민 4,000명 중 수면다원검사 필요성을 아는 사람 33%, 치료 중 0.5%.
3. **왜 병이라고 생각하지 않나?**
   - 수면무호흡·RBD: 증상이 자는 동안 일어나 본인 눈에 보이지 않는다.
     - [사실] RBD 환자의 44%는 자기 증상을 모르고 70%는 "잘 잔다"고 느낀다.
     - [사실] 수면무호흡은 심할수록 본인의 증상 인식이 낮다.
   - 기면증: 낮 졸림을 본인도 느끼지만 오래 이어져 "원래 잠 많은 체질"이 됐다.
     - [사실·정성] 공개 후기에서 "수면 부족 탓", "게으르다"는 말을 들으며 정신력 문제로 여긴 사례가 반복된다.
4. **왜 증상을 보는 옆 사람이 해결하지 못하나?**
   - [사실] 옆 사람은 증상을 본다. 한국 수면무호흡 환자의 목격된 무호흡은 남 73.9%. RBD는 배우자 관찰이 내원의 핵심 계기다.
   - [사실] 증상이 있어도 진료로 이어지지 않는다. 코골이·목격된 무호흡이 있는 사람 중 10년간 의뢰된 건 20% 미만이다.
   - [가설] 본인은 "병원 가봐"라는 말만으로는 움직이지 않는다. 옆 사람이 병원 찾기·예약까지 떠맡고, 본인 대신 설득이 더 쉬운 배우자를 설득하기도 하며, 이 부담 때문에 대부분 한마디로 끝난다. 근거는 작성자 사례 2건과 공개 후기(RBD는 누군가 다친 뒤에야 내원)뿐이고, 이를 직접 잰 연구는 없다.
5. **왜 기존 서비스가 이 간극을 메우지 못하나?**
   - [사실] 장비사 자가테스트, 클리닉 자가진단, 웨어러블, 챗봇 모두 "이미 의심하는 본인"이 찾아와야 작동한다. 관찰자 응답 모드는 레즈메드의 토글뿐이고, 그마저 문항은 본인 기준이다 (조사 범위 내).

**근본 문제 [가설]:** 증상을 보는 사람(옆 사람)과 진료받아야 하는 사람(본인)이 다르다. 진료까지 가는 실행을 옆 사람이 떠맡아야 하는데, 이를 돕는 도구가 없다.

1~3번과 5번은 근거로 확인된다. 4번의 "옆 사람이 실행을 떠맡는다"는 부분과 근본 문제는 가설이며, [핵심 가설](#핵심-가설과-검증)에서 검증 방법을 정한다.

**검증 방식: 두 경로를 모두 열고 비교한다**

어느 쪽이 맞는지 미리 정하지 않는다. 본인 경로(반전 카피 → 본인 체크)와 관찰자 경로(가족·파트너 체크 → 공유)를 함께 열고, 경로별 성과를 비교해 어느 쪽에 힘을 실을지 판단한다.

- **비교 단위:** 경로(본인 / 관찰자) × 관계(배우자·연인 / 자녀 / 부모 / 친구) × 대상 성별·연령대
- **비교 지표:** 경로별 병원 연결률, 공유율, 공유받은 사람의 재방문·병원 연결률
- **필요한 입력:** 자가체크 첫 단계에서 "누구 얘기인지"와 함께 관계, 대상의 성별·연령대를 받는다. 세그먼트 분석의 전제라 설계 단계에서 반영한다.
- **한계:** 실제 내원은 추적할 수 없어 병원 링크 클릭을 대리 지표로 쓴다. 관찰자의 클릭과 본인의 클릭은 의미가 다르다(관찰자 클릭 = 대신 찾아봄). 그래서 공유받은 본인 쪽 지표를 함께 본다. 과제 범위에선 실험 설계와 측정 가능한 이벤트 기록까지 하고, 실제 비교는 출시 후 데이터로 한다.

**과제 기간 내 사전 검증: 메타 광고**

출시 후 데이터를 기다리지 않고, 과제 기간 안에 H3·H4·H5의 방향을 본다.

- **방식:** 카피 2개로 메타 광고를 약 24시간 돌린다. 예산 5~10만 원.
  - A (관찰자): "머리만 대면 5초 만에 잠드는 사람, 주변에 있나요?"
  - B (본인): "5초 만에 잠드는 것도 신호일 수 있어요"
  - C (배우자 동기): 코골이 때문에 각방을 고민하는 배우자를 겨냥한 카피 (문구는 설계 단계에서 정함)
  - 메타는 개인의 건강 상태를 암시하는 문구("혹시 ~세요?")를 제한하는 것으로 알려져 있어 2인칭 질문형은 피한다(정책 확인 필요).
- **보는 것:** 카피별 클릭률(H3), 성별·연령별 클릭 분포(예: 40~60대 여성이 관찰자 카피를 많이 누르면 H4·H5의 방향 근거).
- **전제:** 랜딩 페이지가 과제 시작 후 약 24시간 안에 배포돼야 한다. **`04-plan`에서 랜딩 페이지를 첫 작업 단위로 둔다.** 광고 계정 생성·결제는 작성자가 직접 한다.
- **한계:** 하루치 소액 데이터라 방향만 본다.

H2의 반대 근거는 설계에 반영한다. 옆 사람은 계기를 만들고, 치료 지속은 본인 동기가 만든다. 그래서 공유받은 본인이 보는 화면은 "가족이 걱정한다"에서 끝나지 않고 본인이 얻는 이익(낮 졸림·두통 해소 등)을 함께 보여준다.

## 문제의 크기

### 진료받지 않는 사람이 대부분이다

| 질환 | 근거 |
|---|---|
| 수면무호흡 | 성인 유병률 남 약 4%, 여 약 2% → 추정 약 130만 명. 2025년 진료 19.6만 명 → **약 15%만 진료** (추정) |
| 렘수면행동장애 | 60세 이상 유병률 2.01% → 추정 약 28만 명. 해당 코드(G47.8) 60세 이상 진료 3.2만 명 → **최대 약 12%** (추정) |
| 기면증 | 첫 증상부터 진단까지 **평균 10~11년** |

진료율은 출처 수치를 조합한 직접 계산이다. 계산 과정은 [evidence §3](01-research/evidence.md).

### 방치하면 대가가 크고, 치료하면 극적으로 좋아진다

| 질환 | 치료하지 않으면 | 치료하면 |
|---|---|---|
| 수면무호흡 | 교통사고 위험 약 2.4배, 중증 시 치명적 심혈관 사건 약 2.9배 | 양압기로 낮 졸림 소실, 심혈관 위험 감소 |
| 기면증 | 학업·직장 기능 저하, 10년 넘게 "게으르다"는 오해 | 약으로 증상 크게 호전 ("머리에 햇빛이 비치는 것 같다", VOC) |
| 렘수면행동장애 | 본인·배우자 부상 (배우자 62.5%가 부상 경험), 10년 내 60%가 신경퇴행 질환으로 전환 | 약·침실 안전으로 부상 예방, 신경과 추적으로 조기 대응, 임상시험 참여 기회 |

### 두 가지 유형

- **지연형:** 결국 진단받지만 수년~10년 늦다 (기면증이 대표적).
- **미치료형:** 평생 진단받지 않는다 (수면무호흡, RBD 다수). 진단 지연 통계는 진단받은 사람만 세기 때문에 이쪽은 숫자에 보이지 않을 뿐 더 크다.

두 유형 모두 환자 가치와 비즈니스 가치를 함께 가진다 ([비즈니스 임팩트](#비즈니스-임팩트)).

## 왜 기존 방법으로 안 풀리나

**ChatGPT:** "어느 과에 가야 해?"에는 잘 답한다. 하지만 이 문제의 사람들은 병이라고 생각하지 않으니 **질문 자체를 하지 않는다.** 답이 없는 문제가 아니라 질문이 생기지 않는 문제다.

**기존 플레이어** ([전체 비교](01-research/competitors.md))

| 유형 | 예 | 한계 |
|---|---|---|
| 장비사 자가테스트·병원찾기 | 레즈메드, 필립스 | 본인 문항, 수면무호흡 단일, 자사 장비 판매로 닫힌 연결 |
| 웨어러블·앱 | 갤럭시워치, 애플워치, 에이슬립, SnoreLab | 본인이 기기를 쓰고 의심해야 시작, 수면무호흡 단일 |
| 파트너 녹음 앱 | SoundSleep | 파트너 대상 마케팅이지만 녹음만, 진료 연결 없음 |
| 학회·클리닉 | 대한수면연구학회, 코슬립 | 다질환이지만 본인 문항, 단순 목록이거나 자기 병원 |

"옆 사람 관찰 기반 + 다질환 + 중립적 병원 연결"을 모두 하는 서비스는 찾지 못했다.
레즈메드가 가족 평가 선택지를 두고도 문항을 따로 만들지 않은 점은 **관찰자 수요는 인지됐지만 제대로 풀리지 않았다**는 신호다.

### 기존 병원 연결(비급여 이벤트)과 무엇이 다른가

카테고리를 넓히는 게 아니라 **푸는 문제가 다르다.**

| | 비급여 병원 연결 (예: 제모·교정 이벤트) | 이 서비스 |
|---|---|---|
| 수요 상태 | 드러난 수요. 이미 받고 싶다 | 잠재 수요. 받아야 하는 줄 모른다 |
| 사용자의 질문 | "어디로 갈까?" (선택) | "가야 하나?" (인식) |
| 사용자 | 진료받을 본인 | 증상을 본 옆 사람. 진료받을 사람과 결정하는 사람이 다르다 |
| 전환 장벽 | 가격·후기 비교의 피로 | 인식 부족, 본인 설득, 병원 찾기·예약을 떠맡는 부담 |
| 병원 간 경쟁 축 | 가격(이벤트) | 가격이 같다(급여). 신뢰와 접근성 |
| 병원에 주는 가치 | 다른 병원의 환자를 데려온다 (나눠 갖기) | 원래 오지 않았을 환자를 데려온다 (시장 키우기) |
| 리뷰의 역할 | 가격 대비 결과 비교 | 상업성 불신을 덜고 "믿을 만한 곳"을 고르는 근거 |
| 핵심 기능 | 비교·검색 | 확인 → 설득 → 연결 |

그래서 성공 지표도 다르다. 비급여 연결은 "검색한 사람이 예약했나"를 보지만, 이 서비스는 "몰랐던 사람이 신호를 확인했고, 옆 사람이 병원까지 이었나"를 본다.

## 대상 질환과 선정 이유

**포함:** 수면무호흡, 기면증, 렘수면행동장애

선정 기준은 네 가지다. 본인이 모른다, 옆 사람이 알아챌 수 있다, 치료 가능하다, 진료율이 낮다.
세 질환 모두 수면 전문 진료와 수면다원검사로 진단이 모인다 (기면증은 낮잠 검사 추가).

| 제외 | 이유 |
|---|---|
| 불면증 | 잠을 못 자는 건 본인이 괴로워서 이미 안다 |
| 하지불안증후군 | 본인이 느끼는 감각 증상, 문진으로 진단 |
| 특발성 과다수면 | 본인이 졸림을 안다, 옆 사람 발견과 무관 |
| 지연성 수면위상 증후군 | 본인이 안다, 수면다원검사 대상 아님 |

**우선순위: 수면무호흡이 메인이다.** 진료받지 않는 환자 규모(약 110만 명 추정), 병원 검사·비급여 연결이 모두 수면무호흡에 몰려 있다. 기면증과 RBD는 규모가 작지만 진단 지연·부상 위험이 커서 환자 가치와 차별점을 맡는다. 자가체크 흐름, 카피, 지표는 수면무호흡을 기준으로 설계하고, 기면증(낮 졸림)과 RBD(꿈 행동)는 관찰 신호를 넓히는 보조 분기로 둔다. 반전 카피("머리만 대면 5초 만에 잠드세요?")의 과다 졸림 신호는 수면무호흡과 기면증을 함께 잡는다(작성자 아버지는 같은 신호로 수면무호흡 진단).

질환별로 진입 경로의 비중이 다르다. 수면무호흡·RBD는 옆 사람이 계기가 되는 경우가 압도적이다. 기면증은 두 경로가 모두 있다. 공개 후기에선 본인이나 친구 말이 계기인 경우가 많았고, 작성자 사례에선 옆 사람이 제안하고 예약까지 했다. 그래서 기면증은 관찰자 경로와 반전 카피를 통한 본인 경로를 모두 연다.

## 사용자와 이해관계자

| 누구 | 상황 | 원하는 것 |
|---|---|---|
| **관찰자: 파트너** (주 사용자) | 코골이·숨 멈춤을 듣거나, 낮에 계속 조는 모습을 본다. 코골이 소음 때문에 **본인도 잠을 못 잔다** | 나도 같이 푹 자고 싶다. "이게 병인지" 확인하고, 상대를 병원에 데려갈 근거와 방법 |
| **관찰자: 자녀** | 부모가 잠꼬대하며 발길질하거나, 어디서든 바로 잠든다. 나이 든 부모의 심혈관 건강이 오래 나빠질까 걱정된다 | 부모 본인보다 설득이 쉬운 다른 부모(배우자)에게 알리고, 믿을 만한 병원을 리뷰로 골라 추천하고 싶다 |
| **본인** | 반전 카피("머리만 대면 5초 만에 잠드세요?")에 호기심으로 들어온다 | 내가 정상인지 가볍게 확인 |
| **병원** (수면다원검사 실시기관 742곳, 대부분 이비인후과 의원) | 급여 진료라 가격으로 경쟁할 수 없고, 진료 후 수입이 검사에 몰려 신규 환자가 계속 필요하다 | 숨은 신규 환자 |
| **장비사** (양압기 제조·대여) | 진단받은 환자가 곧 양압기 사용자다. 이미 자가테스트·인식 개선 행사를 직접 한다 | 진단으로 이어지는 환자 |

옆 사람도 직접적인 이해관계자다. 코골이로 잠을 설치고, RBD로 다치고, 졸음운전하는 차에 같이 탄다. 그러니 공유 동기가 단순한 걱정이 아니라 자기 문제이기도 하다.

관찰자의 동기는 관계에 따라 다를 수 있다 [가설].
- **배우자: 내 잠.** 아내가 남편을 병원에 데려간 수면무호흡 사례에서, 동기는 건강 걱정이 아니라 코골이 소음 때문에 같이 자기 힘든 것이었다(전해 들은 사례 1건). 커뮤니티의 "남편 코골이·각방" 고민과도 맞는다.
- **자녀: 부모 건강.** 작성자는 아버지의 심혈관 건강이 오래 나빠질까 걱정했다.

그래서 관찰자 카피와 결과 메시지는 관계별로 다르게 쓴다. 배우자에겐 "같이 푹 자기", 자녀에겐 "부모님 건강"이다. 다만 공유받은 본인에게 "네 코골이 때문에 내가 못 잔다"로 보내면 탓하는 말이 된다. 본인에게는 본인이 얻는 이익(낮 졸림·두통 해소)을 보여준다.

## 목적 (Why)

드러나지 않은 수면장애 환자를 수면 전문 진료로 데려온다. 환자는 진단을 수년 앞당겨 피해를 줄이고, 병원은 원래 오지 않았을 환자를 더 일찍 만난다.

수요를 **새로 만드는 게 아니라 깨우는 것**이다. 환자는 이미 아프고 대가를 치르고 있다. 다만 병이라는 인식이 없어 수요로 드러나지 않았을 뿐이다.

## 비즈니스 임팩트

임팩트는 **이 서비스 자체** 기준으로 본다. 원자료: [business-model](01-research/business-model.md), [retention](01-research/retention.md).

### 1. 시장: 아무도 깨우지 못한 수요

- [추정] 진료받지 않는 수면무호흡 환자 약 110만 명 (추정 환자 약 130만 − 2025년 진료 19.6만).
- [사실] 수면다원검사 건수는 급여화 직후 2019년(82,198건)에 정점을 찍고 이후 소폭 줄었다. 이미 알던 수요는 흡수됐고, 숨은 환자 유입이 병목이다.
- [추정] 숨은 환자의 1%(약 1.1만 명)만 진료로 와도 병원 검사 매출만 약 66억 원이다.

### 2. 고객: 수면다원검사를 하는 동네 이비인후과

- [사실] 수면다원검사 실시기관은 **전국 742곳**, 그중 81%가 의원이고 이름에 "이비인후과"가 들어간 곳이 515곳이다. "수면클리닉" 간판은 적지만 실제 검사는 동네 이비인후과가 한다.
- [사실] 이비인후과 의원은 매출의 88%가 건강보험이고(진료과 중 최고), 내원 하루당 진료비가 약 3.2만 원으로 평균(약 4.9만 원)보다 낮다.
- [추정] 이들에게 수면다원검사 1건(의원 수가 578,734원)은 **내원 약 18일분 진료비**다. 해당 진료과 안에서는 드문 고단가 항목이다.
- [사실] 비급여로도 이어진다. 단순 코골이 수술은 의원 평균 약 382만 원, 수면무호흡용 구강내장치(치과)는 100~150만 원이다.

**왜 이 고객에게 이 서비스가 필요한가**
- 건강보험 진료라 어느 병원이나 가격이 같다. 비급여처럼 가격 이벤트로 환자를 끌 수 없다.
- 환자가 검색하지 않아 살 키워드 자체가 적다. 필요한 건 경쟁 병원을 이기는 광고가 아니라 **수요를 깨우는 채널**이고, 병원 하나가 혼자 하기 어렵다.
- [사실] 진료 이후 병원 수입은 검사에 몰린다. 양압기 관리에 병원이 받는 별도 수가가 없고, 순응기간 이후엔 연 1회 재진 수준이다. 그래서 병원은 **신규 환자가 계속 필요하다.**

### 3. 수익 모델

| 수익원 | 형태 | 조건 |
|---|---|---|
| 병원 광고 (주) | 정액 광고 | 의료법 27조: 환자 수·진료비와 연동된 수수료는 환자 알선으로 위법(대법원 2018도20928, 강남언니 1·2심 유죄). 정액 광고비는 광고로 인정 |

**장비사는 수익원으로 잡지 않는다.** 장비사에게 환자 1명의 가치는 병원보다 크다(양압기 대여 기준금액 월 7.6만 원, 대여료는 업체로 간다). 레즈메드·필립스가 직접 인식 개선에 돈을 쓰는 것도 숨은 환자 발굴의 가치를 보여준다. 하지만 이 서비스는 후원 여부와 무관하게 진단 환자를 늘리고, 그 이익은 모든 장비사가 나눠 갖는다. 중립성 때문에 후원사에 줄 수 있는 대가(병원 목록 노출 등)도 없다. 후원할 동기가 없다. 장비사가 실제로 경쟁하는 지점은 진단 이후 환자가 대여 업체를 고르는 단계인데, 이는 이번 범위 밖이다(확장 시 고려).

### 4. 환자와 사회

- 진단을 수년 앞당긴다. 기면증은 평균 10~11년 지연된다.
- 미치료 수면무호흡은 교통사고 위험 약 2.4배, 중증 시 치명적 심혈관 사건 약 2.9배다.

### 수면 진료 시장의 마케팅 현황 ([marketing](01-research/marketing.md))

- 메시지는 전문성(전문의 이력, 검사 실적, 검사실 수)과 편의(대기 없음)가 중심이다. 이미 의심하는 사람에게 "우리 병원"을 고르게 하는 마케팅이다.
- 자가진단은 없거나 본인 기준이다. 관찰자가 응답하는 모드를 가진 클리닉은 없다.
- "남편 코골이·각방" 고민은 커뮤니티에 많은데, 이를 겨냥한 클리닉 캠페인은 없다.
- 기면증·RBD는 진료 메뉴에만 있고 들어오는 경로가 없다.
- 의료법 56조가 치료경험담 광고를 막아 병원은 경험담을 직접 쓰기 어렵다. 제3자 리뷰는 이 빈틈을 채운다.
- 마케팅 니즈는 정황상 중상 수준이다. 대행사가 수면의원 사례로 "환자 3배"를 내세우고, 의원들이 검사실 수와 대기 시간으로 경쟁한다. 가동률·광고 단가 같은 직접 수치는 확인하지 못했다.

### 약점 (알고 고른 것)

| 약점 | 내용 | 왜 그래도 이 문제인가 |
|---|---|---|
| 마진이 얇다 | 급여 수가로 가격이 고정되고, 수면기사 인건비가 급여화 후 2배가 됐다는 발언이 있다 | 고객 기준으론 고단가 항목이고, 비급여(코골이 수술·구강내장치)로도 이어진다 |
| 리텐션이 약하다 | 양압기 장기 순응률은 전국 데이터로 약 3.8년 시점 12.2%. 병원 수입은 첫해에 몰린다 | 오히려 병원이 신규 환자를 계속 필요로 하는 이유가 된다 |
| 기면증·RBD는 규모가 작다 | 기면증 진료 인원 연 9천 명대 | 광고 매출은 수면무호흡이 끌고, 기면증·RBD는 환자 가치와 차별점을 맡는다 |
| 사용자 수요의 증거가 아니다 | 위 근거는 공급자 측 지불 의사다 | 사용자 측은 진료율·진단 지연 통계와 VOC로 따로 뒷받침하고, 출시 후 지표로 검증한다 |

미확인: 수면클리닉 수익률, 검사실 손익, 키워드 광고 단가.

## 진짜 장벽은 비용이 아니다

VOC([voc](01-research/voc.md))에서 비용은 장벽이 아니었다. 검사 본인부담 12~20만 원대를 "생각보다 싸다"고 느꼈고, 비용 때문에 망설였다는 진술은 없었다. 비용 안내는 병원이 상담하면서 할 일이다.

| 장벽 | VOC | 대응 |
|---|---|---|
| 증상 과소평가 | "조금 피곤할 뿐", "원래 잘 자는 체질", "심한 잠꼬대" | 관찰 내용을 정리한 결과 리포트로 객관화 |
| 본인이 스스로 움직이지 않음 | 옆 사람이 병원 찾고 예약까지 해줘야 감 (작성자 경험) | 옆 사람이 바로 병원을 고르는 흐름 |
| 본인은 설득이 어렵다 | 아빠는 안 듣고, 엄마가 설득하기 더 쉬웠다 (작성자 경험) | 본인뿐 아니라 배우자에게도 공유 |
| 하룻밤 검사 부담 | 하룻밤 센서 부담으로 거절 | 첫 목적지를 검사가 아닌 외래 진료로. 검사 과정은 미리 보여주는 정보로 |
| 병원 상업성 불신 | 병원의 수면용품 홍보를 보고 결과까지 의심 | 특정 병원·장비사에 묶이지 않은 중립 연결 |

**데이터가 마음을 바꾼다.** 하룻밤 검사를 거절한 사람이 수면 앱 기록을 보고 검사를 받았고, 워치 기록을 보고 병원에 간 사례도 있다. 객관적 근거를 쥐여주는 것이 효과가 있다.

## 솔루션 방향

상세 UX는 `02-design-pass`에서 정한다.

1. **유입:** 반전 카피로 들어온다. 예: "혹시 머리만 대면 5초 만에 잠드세요?" 본인이 장점으로 여기는 습관을 증상일 수 있다고 뒤집는다. 근거: 낮잠 검사(MSLT)에서 평균 8분 이하면 병적 졸림, 정상 성인은 10~20분이다. 다만 밤 입면 시간과 같은 기준은 아니니 "검사해볼 만한 신호" 수준으로 쓴다.
2. **자가체크 (1~2분):** 첫 단계에서 "내 얘기 / 가족·파트너 얘기"를 고른다. 관찰자를 고르면 문항 주어가 바뀐다 (예: "자는 동안 숨이 멈추는 걸 본 적 있나요?"). 검증 척도(ESS, STOP-Bang 등)는 상업 사용에 라이선스가 필요하므로, 판단 기준을 참고한 자체 관찰 문항을 만들고 참고 출처를 밝힌다.
3. **결과:** "진단이 아니라 진료를 권하는 신호"로 보여준다. 관찰 내용을 정리한 리포트 형태다.
   - **관찰 기록 가이드:** "코골이·숨 멈춤·발길질을 30초만 찍어서 진료 때 보여주세요." 분석은 하지 않는다.
   - **RBD는 공포를 앞세우지 않는다.** "자다가 다칠 수 있어요"와 전문의 상담 권유가 중심이다. 파킨슨병 연관은 상담에서 다룰 정보로 둔다.
4. **공유:** 본인에게, 또는 함께 데려갈 가족에게 보낸다.
5. **병원 연결:** 수면 전문 진료 병원을 보여주고 외부 링크로 보낸다. 첫 목적지는 수면다원검사가 아니라 **외래 진료**다. 검사를 할지는 의사가 판단하고, 건강보험 적용도 의사 판단이 있어야 충족된다.

## 크롤링 요구사항 대응

| 대상 | 역할 | "같은 문제를 푸는 서비스"인가 |
|---|---|---|
| 레즈메드 수면다원검사 병원찾기 (337곳, 병원별 상세 페이지) | 기본 병원 데이터, 외부 링크 | 그렇다. 양압기 회사로, 미진단 환자를 진단으로 잇는 것이 사업 모델이고 자가테스트·병원찾기를 직접 운영한다 |
| 대한수면연구학회 수면클리닉 찾기 (95곳, 병원 홈페이지) | 학회 인증 배지로 신뢰도 보강 | 그렇다. 학회가 수면클리닉 연결을 직접 제공한다 |

두 곳 모두 robots.txt가 해당 경로를 허용하고 정적 HTML이다. 최종 구성은 `03-tech-spec`에서 확정한다 ([crawl-targets](01-research/crawl-targets.md)).

## 목표 / 성공 기준

| 구분 | 지표 | 정의 | 이유 |
|---|---|---|---|
| **주 지표** | 병원 연결률 | 자가체크를 마친 사람 중 병원 외부 링크를 클릭한 비율 | 병원 광고 수익 모델의 근거가 되는 숫자다. 링크를 누르는 사람이 곧 실행을 떠맡은 옆 사람이다 |
| 보조 | 공유율 | 결과를 공유한 비율 | 옆 사람 → 본인·가족으로 이어지는 설득 경로, 신규 유입 |
| 보조 | 자가체크 완료율 | 시작 대비 완료 | 유입 카피와 문항 부담 검증 |
| 가설 검증 | 관찰자 비율 | 첫 단계에서 "가족·파트너 얘기"를 고른 비율 | 옆 사람 가설을 출시 후 바로 검증한다 |

실제로 진료를 받았는지는 추적할 수 없다. 그래서 병원 링크 클릭을 대리 지표로 쓴다. 기준선 데이터가 없어 목표 수치는 정하지 않고, 측정 가능하게 만드는 것을 이번 범위의 기준으로 삼는다.

## 가정 / 리스크 / 미정 사항

| 구분 | 내용 | 대응 |
|---|---|---|
| **리스크 1순위** | **유입.** 병이라 생각하지 않는 사람은 이 서비스도 검색하지 않는다. 반전 카피와 공유가 먹힌다는 건 검증되지 않은 가설이다 | 유입 채널을 명시한다 (병원 찾기 플랫폼 내 노출, SNS 공유형 테스트). 완료율·공유율로 검증 |
| 가설 | 옆 사람 관련 가설(H1~H4)이 틀릴 수 있다. 배우자 권유 비율을 직접 잰 연구는 없다 | [핵심 가설과 검증](#핵심-가설과-검증)의 지표로 출시 직후 확인한다. H1이 틀리면 본인 경로(반전 카피) 비중을 키운다 |
| 가설 | 기면증은 본인 경로와 옆 사람 경로가 모두 있다 | 공개 후기는 본인·친구 말이 계기, 작성자 사례는 옆 사람이 계기. 두 경로를 모두 열고 관찰자 비율을 질환별로 본다 |
| 리스크 | 자가체크가 진단처럼 보이면 불안을 키우거나(오탐) 괜히 안심시킨다(미탐) | "진단이 아닌 진료 권유 신호" 문구 원칙, 결과와 무관하게 걱정되면 진료 권유 |
| 리스크 | RBD 결과가 공포 마케팅으로 보일 수 있다 | 부상 예방·전문의 상담 중심, 파킨슨 연관은 앞세우지 않음 |
| 리스크 | 크롤링 대상 사이트 구조 변경·차단 | 수집 결과를 DB에 저장해 보여주고, 실시간 크롤링하지 않는다 (`03-tech-spec`) |
| 미확인 | RBD 진료 인원 (별도 질병코드 없음), 기면증 해외 유병률 1차 출처, 수면클리닉 수익률·광고 단가 | 진료율은 상한 추정으로만 쓴다 |

## 기획 과정에서 검토한 질문

| 질문 | 결론 |
|---|---|
| 문제 후보는? (비급여 비교, 건강검진, 증상→진료과, 실손 청구) | 증상→진료과에서 출발했지만, 작성자 경험(기면증)을 계기로 "치료법은 있는데 병인 줄 몰라 방치되는 문제"로 옮겼다 |
| 증상→진료과 안내는 ChatGPT로 되지 않나? | 된다. 그래서 "답"이 아니라 "질문이 생기지 않는 사람"으로 문제를 옮겼다 |
| 야간·주말 진료 vs 체질로 여기는 질환? | 야간 진료는 이미 있는 수요를 연결하는 문제라 경쟁이 많다. 후자는 없던 수요를 깨운다 |
| 범위는? | 질환 하나(수면장애)로 좁혀야 48시간 안에 흐름을 완성도 있게 만든다 |
| 누가 쓰나? | 옆 사람. 본인은 익숙해져 모른다 (아버지·남자친구 공통) |
| 본인은 못 데려오나? | 반전 카피("머리만 대면 5초 만에 잠드세요?")로 본인도 호기심으로 들어온다. 자랑으로 여기는 습관을 건드린다 |
| 비즈니스 임팩트가 있나? | 있다. 숨은 환자 유입이 수면 진료 시장의 병목이다. 세부는 아래 수익 구조 질문들 참고 |
| 진료 이후 병원 리텐션은? | 약하다. 양압기 장기 순응률은 약 3.8년 시점 12.2%이고, 병원은 양압기 관리 수가가 없어 수입이 첫해 검사에 몰린다. 그래서 병원은 신규 환자가 계속 필요하다 |
| 기면증 환자 70%가 1년 안에 약을 끊는다던데? | "첫 약"을 바꾼 비율이라 치료 중단이 아니다(약 교체·병용 포함, 미국 1형). 이탈 근거로 쓰지 않는다 |
| 양압기 대여료가 업체로 가면 광고주가 업체일 수도 있나? | 업체에게 환자 가치는 크지만, 이 서비스는 후원 없이도 진단 환자를 늘려 모든 업체가 이익을 나눠 갖는다. 중립성 때문에 줄 대가도 없어 후원 동기가 없다. 수익원에서 제외하고, 진단 이후 대여 업체 선택 단계는 확장 시 고려 |
| 병원은 세 질환 진료만으로 광고할 만큼 돈이 되나? 비급여보다 낮지 않나? | 비급여 진료과와 비교하면 낮다. 하지만 실제 고객인 이비인후과 의원(매출 88%가 급여, 내원당 약 3.2만 원) 기준으론 검사 1건이 내원 약 18일분인 고단가 항목이고, 코골이 수술·구강내장치 같은 비급여로도 이어진다 |
| 수면클리닉은 실제로 적은가? | 아니다. 수면다원검사 실시기관 742곳, 대부분 동네 이비인후과다 |
| 수면클리닉이 전국 95곳뿐인가? | 아니다. 95곳은 학회 인증 수다. 심평원 수면다원검사 실시기관은 742곳이고 81%가 의원, 대부분 이비인후과다 |
| 수면장애는 몇 종류고, 더 맞는 게 있나? | ICSD-3 기준 7개 군. 조사 결과 렘수면행동장애가 "본인 모름 + 옆 사람 발견"에 가장 잘 맞아 추가했다. 불면·하지불안 등은 본인이 알아서 제외 |
| 렘수면행동장애 유병률이 높은데 진료는 얼마나 받나? | 유병률은 60세 이상 기준이다. 별도 질병코드가 없어 진료 인원은 상한으로만 추정한다(최대 약 12%) |
| 세 질환 모두 수면다원검사로 진단되나? | 그렇다. 기면증은 다음 날 낮잠 검사가 추가된다 |
| 왜 수면다원검사로 연결하나? | 하지 않기로 했다. 첫 행동은 외래 진료이고 검사는 의사가 판단한다. 하룻밤 검사를 앞세우면 문턱만 높아진다 → 목적지를 "수면 전문 진료"로 바꿨다 |
| 건강보험 적용을 알려줘야 하나? | 의원이 상담에서 알려준다. VOC에서도 비용은 장벽이 아니었다 |
| 레즈메드는 이 문제를 푸는 서비스가 맞나? | 맞다. 미진단 환자 발굴이 양압기 회사의 사업 모델이고, 자가테스트·병원찾기를 직접 운영한다. 수요가 있다는 공급자 측 증거이기도 하다 |
| 같은 문제를 푸는 서비스가 있나? | 세 조건(관찰자 문항, 다질환, 중립 연결)을 모두 갖춘 곳은 없다 |
| 수요를 창출하는 건가? | 새로 만드는 게 아니라 드러나지 않은 수요를 깨운다 |
| 지연형과 미치료형 중 어느 쪽인가? | 둘 다다. 기면증은 지연형, 수면무호흡·RBD는 미치료형이 다수다 |
| 지연형은 환자 가치뿐인가? | 아니다. 병원도 10년 뒤보다 지금 환자를 원한다. 먼저 연결하는 쪽이 환자를 잡는다 |
| RBD를 일찍 알면 할 수 있는 게 있나? | 부상 예방, 악화 약물 회피, 신경과 추적, 운동, 임상시험 참여, 미래 준비 |
| 앱에서 수면을 측정·진단하면? | 하지 않는다 (규제·정확도·이탈·범위). 대신 분석 없는 관찰 기록 가이드를 넣는다 |
| 옆 사람 가설 근거가 부족하지 않나? | 부족하다. 가설로 명시하고 출시 후 관찰자 비율로 검증한다. 수면무호흡 정량 근거는 보강 중 |
| 수면클리닉은 지금 어떻게 마케팅하고, 니즈는 얼마나 되나? | 전문성·편의 중심의 "병원 고르기" 마케팅이고 관찰자·기면증·RBD 유입 경로는 비어 있다. 니즈는 정황상 중상. 경험담 영역은 의료법상 클리닉이 못 하고 리뷰 플랫폼이 할 수 있다 |
| 수면클리닉은 치과·피부과만큼 경쟁이 있나? | 덜할 것이다. 환자가 검색하지 않아서다. 그래서 필요한 건 경쟁 광고가 아니라 수요를 깨우는 플랫폼 역할이다 |
| 기면증은 본인이 가는 경우가 많지 않나? | 공개 후기는 그렇지만 작성자 사례(남자친구)는 옆 사람이 제안하고 예약했다. 두 경로를 모두 연다 |
| 본인과 옆 사람 중 누구를 설득해야 하나? | 미리 정하지 않는다. 두 경로를 모두 열고 경로·관계·대상 세그먼트별 병원 연결률을 비교한다. 세부 가설: 중년~노년 남성은 배우자·딸 경유가 효과적(H5) |
| "옆 사람"은 사실인가 가설인가? | 가설이다. 옆 사람이 증상을 본다는 건 근거가 있지만, 실행을 떠맡는다는 건 작성자 사례와 정성 근거뿐이다. 5 Whys와 요약에 [사실]/[추정]/[가설]을 표시하고, 가설 H1~H4에 검증 지표를 붙였다 |
| 옆 사람이 "병원 가봐"라고 하면 가나? | 안 간다. 옆 사람이 병원을 찾아 예약까지 해주거나, 설득이 더 쉬운 배우자를 통해야 간다 → 전환의 주인공은 옆 사람이다 |
