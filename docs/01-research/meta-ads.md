# 메타 광고 유입 검증

[솔루션 0단계 "닿기"](../01-solution-direction.md#솔루션-방향)를 실제 숫자로 처음 확인하는 광고다. 검증 계획은 [01-validation](../01-validation.md#메타-광고-유입-검증)에 있다.

## 목적

> **검색하지 않는 배우자를 데려올 수 있나, 얼마에?**

- 서비스가 병원에 파는 것은 "판단을 마친 배우자"다([비즈니스 임팩트](../01-business-impact.md)). 배우자가 들어오지 않으면 체크·결과·병원 목록도, 병원 광고 수익도 성립하지 않는다.
- 솔루션 문서도 유입을 1순위 리스크로 둔다. 한국에서 배우자를 광고로 데려올 수 있는지 보여주는 공개 자료는 찾지 못했다.
- 광고 목표는 "랜딩 페이지 조회"로 둔다. 참여 목표로 돌리면 메타가 반응할 사람에게만 보여줘 클릭이 안 나온다.
- 어떤 메시지가 이기는지는 보지 않는다. 메타가 예산을 반응 좋은 소재에 몰아주므로 소재별 숫자는 참고만 한다.

## 설계

| 항목 | 값 |
|---|---|
| 구조 | 캠페인 1개, 광고 세트 1개, 소재 4개. 예산 분배는 메타에 맡긴다 |
| 목표 | 트래픽(랜딩 페이지 조회) |
| 타겟 | 40~60대 여성, 국내 |
| 예산 | 5만 원. 배포 직후 남은 시간에 몰아서 쓴다 |
| 랜딩 | 배우자 체크 시작 화면 |
| 전제 | 서비스 배포, 이벤트 기록(체크 완료, 병원 링크 클릭) 동작 |

**볼 숫자**

| 숫자 | 의미 |
|---|---|
| 클릭률, 클릭당 비용 | 배우자가 이 주제에 반응하나 |
| 체크 완료율 → 병원 링크 클릭률 | 들어온 배우자가 "판단을 마친 배우자"까지 가나 |
| 병원 링크 클릭 1건당 비용 | 병원 광고비로 이 유입 비용을 감당할 수 있나. 비즈니스 임팩트의 핵심 숫자 |

**한계**
- 과제 기간이 24시간 남아 광고는 길어야 10시간 안팎 돈다. 메타 학습 기간이라 숫자가 흔들리고, 병원 링크 클릭은 몇 건뿐이라 초기 신호로만 본다.
- 메타는 50~60대 도달이 약해 40대 위주로 치우친다.
- 배포가 늦어 광고를 못 돌리면 이 문서를 출시 후 첫 검증 계획으로 둔다.

## 작성 제약

- **배우자 시점:** 당사자가 느끼는 증상이 아니라 배우자 눈에 보이고 들리는 장면으로 쓴다. 모든 소재가 "남편"으로 부른다.
- **메타 개인 특성 정책:** 보는 사람 **본인**의 건강·나이 같은 특성을 짚으면 반려된다("60년대생 여성"). 남편의 코골이나 각방 같은 제3자·생활 상황 표현은 괜찮다.
- **효과 보장 금지:** "사라집니다"가 아니라 "사라질 수 있어요".
- **수치는 출처 있는 것만:** [evidence](evidence.md)의 [사실] 항목만 쓴다.
- **심혈관 위험은 치료와 엮지 않는다.** 무작위 시험(SAVE, NEJM 2016)에서 양압기로 심혈관 사건이 줄지 않았다. 근거 수치가 치료하지 않은 중증 기준이라 숫자 없이 가능성만 말한다.
- **후기는 실제 인용만:** 실제로 한 말이고 광고 사용 동의를 받은 경우에만 쓴다. 지어낸 후기는 표시광고법상 거짓 후기다. 의료법 56조는 의료기관·의료인을 알리는 광고에 적용되어 직접 대상은 아니지만, 병원 광고 수익으로 병원에 보내는 구조라 효과를 단정하지 않는 문장을 쓴다.

## 소재

공통 필드:

| 필드 | 문구 |
|---|---|
| 헤드라인 | 병원 갈 일인지 무료로 3분 체크 |
| 설명 | 옆에서 본 대로 답하면 돼요 |
| 버튼 | 더 알아보기 (메타 고정 목록) |

| 소재 | 각도 | 기본 문구 | 근거 | 시안 |
|---|---|---|---|---|
| A | 치료 가능 (후기) | "20년 참은 남편 코골이, 치료받고 없어져서 너무 신기해요" - 68년생 여성 이모씨 | 작성자 어머니 인터뷰([voc](voc.md)). 사용 동의 받음 | [A](meta-ads/A.png) |
| C | 수면 피해 | 남편 코골이로 잠 못 이루는 밤, 평생 이렇게 살아야 할까요? | — | [C](meta-ads/C.png) |
| D1 | 졸음 운전 위험 | 밤새 코 골더니, 운전하다 꾸벅? 수면무호흡이면 사고 위험 2.4배. | 교통사고 위험 약 2.4배(Tregear et al., JCSM 2009) | [D1](meta-ads/D1.png) |
| D2 | 심혈관 위험 | 문 닫아도 들리는 남편 코골이, 방치하면 심근경색·뇌졸중까지 올 수 있어요. | 미치료 중증 OSA: 심근경색·뇌졸중 사망 OR 2.87(Marin et al., Lancet 2005, 남성 관찰 연구) | [D2](meta-ads/D2.png) |

- 각도가 서로 다른 소재를 넣어, 메타가 반응 좋은 쪽을 찾게 한다.
- A의 "20년"은 실제와 맞는지 확인한 뒤 쓴다.

### 예비 소재

반려되면 바꿔 넣는다.

| 대신할 소재 | 기본 문구 | 시안 |
|---|---|---|
| A | 20년 참은 남편 코골이, 치료로 사라질 수 있어요. (후기형이 반려될 때) | [A-alt](meta-ads/A-alt.png) |
| — | 코골다 컥 하는 남편, 이 병일 수 있어요. "이 병"이 낚시성으로 반려될 위험이 있어 기본 구성에서 뺐다 | [B](meta-ads/B.png) |
| C | 남편 코골이 때문에 각방 쓰세요? 참는 것 말고 방법 있어요. | — |

- "남편 코골이로 귀마개하는 60년대생 여성 찾습니다"는 나이를 짚어 반려 위험이 커서 쓰지 않는다.

## 이미지

피드에서는 이미지 안 글자가 가장 먼저 읽힌다. 기본 문구를 이미지 안에 그대로 넣는다.

| 영역 | 내용 |
|---|---|
| 0. 서비스명 | 좌상단 작게 "코골이체커". 누가 하는 광고인지 보이게 |
| 1. 후킹 문구 | 기본 문구 앞부분. 크게 |
| 2. 보조 문구 | 기본 문구 뒷부분 또는 인용 출처. 작게, 1줄 |
| 3. 장면 | 소재별 장면 (A "조용~" 말풍선과 신기해하는 아내, C 귀마개 낀 아내와 새벽 시계, D1 졸며 운전하는 남편, D2 닫힌 문 너머 코골이) |

- 4. 출처: 근거가 논문인 D1·D2는 맨 아래에 작게 출처 한 줄을 넣는다.
- 1080×1080. 레이아웃, 폰트, 색은 모두 같게 두고 문구와 장면만 바꾼다.
- 이미지 바로 밑에 메타 CTA 버튼이 붙으므로 이미지 안에 버튼이나 라벨을 넣지 않는다. "무료로 3분 체크"는 헤드라인에 맡긴다.
- 한계: 인스타 피드는 헤드라인이 거의 안 보여서 "무료로 3분 체크"가 묻힌다.
- 얼굴이 정면으로 나오는 사진, 의료기기, 병원은 넣지 않는다.
- **일러스트를 쓰는 이유:** AI 생성 실사 사진은 가짜처럼 보여 신뢰를 깎고, 차분한 정보형 톤은 피드에서 묻힌다. 일러스트로 눈에 띄게 하고, 신뢰는 서비스명·출처로 보강한다. 광고를 누른 사람이 끊기지 않게 랜딩 첫 화면에 같은 일러스트와 남색·노랑 색을 이어 쓴다.
