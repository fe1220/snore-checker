# 직접 조사 질문지

## 1. 가족 인터뷰 (각 15분)

**아버지**
1. 검사 전, 머리만 대면 잠드는 걸 어떻게 생각했어요?
2. 처음 검사 얘기를 들었을 때 왜 안 가려고 했어요?
3. 결국 가게 된 계기는 뭐였어요? 누구 말이 컸어요?
4. 양압기 쓰고 나서 달라진 게 있어요? 계속 쓰고 있어요?

**어머니**
1. 아버지 수면에서 이상하다고 느낀 적 있었어요?
2. 딸 말을 듣고 어떻게 아버지를 설득했어요?
3. 아버지는 딸 말보다 엄마 말을 더 잘 듣는 편이에요? 왜 그럴까요?

**남자친구**
1. 검사 전, 잠이 많은 걸 어떻게 생각했어요?
2. 검사를 제안받았을 때 기분이 어땠어요?
3. 예약까지 해주지 않았어도 갔을 것 같아요?
4. 진단과 치료 후 달라진 건 뭐예요?

## 2. 지인 설문 (2분)

1. 함께 사는 가족·연인이 다음 중 하나라도 있나요? (코골이 / 자다 숨이 멈춤 / 잠꼬대하며 몸을 움직임 / 낮에 심하게 졺 / 없음)
2. 그 사람은 누구인가요? (배우자·연인 / 부모 / 자녀 / 기타) · 성별 · 연령대
3. 병원에 가보라고 권해본 적 있나요? (예 / 아니오)
4. (예) 반응은? (갔다 / 안 갔다 / 생각해본다고 했다)
5. (아니오) 권하지 않은 이유는? (병이라 생각 안 함 / 말해도 안 들을 것 같음 / 어디로 가야 할지 모름 / 기타)
6. 그 사람을 병원에 보내려면 누구를 설득하는 게 가장 쉬울까요? (본인 / 배우자 / 자녀 / 기타)

## 3. 카피 테스트 (인스타 스토리 투표)

- A: "혹시 머리만 대면 5초 만에 잠드세요?"
- B: "수면장애 자가진단 해보세요"
- 질문: "어느 쪽을 눌러보고 싶나요?"
