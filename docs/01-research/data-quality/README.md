## 권장 조치
1. 링크 요건은 충족. 조치 없음.
2. JSON은 손으로 고치지 않는 규칙이므로 크롤러에 **보정 테이블(id → 값)** 을 두는 것이 가장 단순: 봄봄·코앤365 좌표, busancoent 이름("코엔이비인후과의원"), 경북 2곳 region → 경남. 근거를 주석과 troubleshooting.md에 남긴다.
3. 봄봄은 상세 페이지 좌표(37.701035,126.930725)를 보정값으로 쓸 수 있다. 코앤365는 상세 페이지도 같은 틀린 좌표라 주소 지오코딩 필요.
4. 일반 방어: 크롤러에서 region을 원본 district 대신 주소 첫 토큰으로 검증(불일치 시 주소 우선), 이름 40자 초과 경고.
5. 1~7km 이상치(울산대병원, 송도 2곳, 비에스코아, 세종 2곳)는 "내 주변 순" 순서에만 영향. 시간이 없으면 알려진 한계로 문서화.
6. 동명 17종: 카드에 주소가 항상 보이는지 확인.
