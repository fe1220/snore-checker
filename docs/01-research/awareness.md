# 코골이·수면무호흡 대중 인지도

조사일 2026-10-01. 한국 자료에 "코골이가 질환 신호인가 / 치료 가능한가 / 건강보험이 되는가"를 그대로 묻는 문항은 없다.

## 한국

| 내용 | 출처 |
|---|---|
| 수면무호흡 진단에 수면다원검사가 필요한 걸 앎 33.0%, 모름 67.1% (21~69세 4,000명, 2022) | Kim KT et al., J Sleep Med 2022 https://www.e-jsm.org/journal/view.php?viewtype=pubreader&number=343 |
| 표준 치료로 생활습관 개선 48.9%, 양압기 25.9%, 수술 12.0%, 구강장치 6.8%를 고름 | 같은 논문 |
| 고위험군(STOP 2점 이상) 1,044명 중 치료 중 19명(약 1.8%) | 같은 논문 |
| 수면무호흡 치료 필요성 인식 71.4%, 양압기 인지 26%, 치료 효과 인식 29.7%. 코골이 증상자 중 치료 시도 없음 47.9% (성인 2,000명, 2024) | 필립스코리아·한국리서치, 데일리팜 2025-03 https://www.dailypharm.com/Users/News/NewsView.html?ID=321153 |
| 코골이 24.8%, 코골이 증상자 198명 중 53.5% 치료 시도 없음. 수면무호흡을 알게 된 경로(수면무호흡 환자 274명): **동거인이 호흡 이상을 알아차림 37.6%, 심한 코골이로 동거인 수면 방해 25.5%**, 나머지 항목·수치는 기사에 없음. 단일·복수 응답 여부 미확인 (조사: 성인 800명 + 양압기 사용자 201명) | 필립스코리아·한국리서치, 머니투데이 2026-03-05 https://www.mt.co.kr/thebio/2026/03/05/2026030510165431759 |

- 치료하지 않은 이유 분포, 건강보험 인지도: 국내 자료 없음.

## 해석

"문제인 건 막연히 알지만(필요성 인식 71%), 질환이고 검사·양압기로 치료하며 어디로 가야 하는지는 모른다"에 가깝다.
증상 정보보다 **경로 정보**(어디서, 무엇을)가 비어 있다. 한국의 이유 분포 자료가 없어 이 해석은 추론이다.
